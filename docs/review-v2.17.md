# 2.17 明确记忆偏好与主动通知

状态：已发布。基于 2.16 的默认目的地增加可撤销的记忆绑定；本版没有跨进程恢复或程序 A/B 更新。

## 实现与独立审查

配置保存确切的偏好 ID、版本与结构化目的地；宿主只读已有三表主键连接取得可信来源和摘要，不读取正文、关系或冲突列表，不调用记忆检索或模型。证据随原通知、receipt、ingress 与 outbox 固定保存。默认与记忆依据、不同来源或版本不混批；实际发送时重新核对当前绑定、事实状态及原始摘要。

新独立事项选不到有效偏好时使用明确默认并显示原因；旧依赖项失效后保持原目的地并 blocked，不更换地址。更正、冲突解决、遗忘、关闭记忆、取消绑定、权限撤销与 unknown 的行为均独立覆盖。新的配置选择在 stage、真实应用前及组件关闭等待后复核；未改变的旧失效绑定不阻碍暂停、撤销或无关配置。

独立静态尾审未发现产品阻断。检查覆盖三表 PK 查询计划、有限标量投影、事务不被只读检查提交、宿主证明与地址授权隔离、冻结记录的完整生命周期，以及 UI 版本、暂停和撤销行为；修正文档中遗留的“记忆选路尚未接入”描述。

## 定向验证

作者在共享 guard 下完成 **165 项 Python 定向回归（含 31 项新增）**，**22 项前端**，8 个产品源码严格类型和 10 个文件 Ruff/格式检查。最大峰值 209.3 MiB、swap 0。使用真实临时 Store 与既有 Memory 来源登记、更正、冲突解决和遗忘入口，HTTP、模型及外部平台均使用替身。

覆盖 close-await 期间证据失效、附件读取后撤销、已发首段后阻止后续发送、同 ID 新版本分批、重开 Store 后保持冻结地址与阻塞事实；前端沿实际表单收集/补丁保存路径验证，并保留普通记忆核查的 ID/版本。没有连接真实渠道账号或实际发送语音。
