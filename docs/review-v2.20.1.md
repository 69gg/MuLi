# 2.20.1 热重载与后台压缩连续性

状态：2.20.1 已发布。精确候选/main 八项 CI 与十一项发行作业全部通过，GitHub/PyPI 两个构件的大小和摘要一致。本版继承 2.20 的升级准备，跨版本 A/B 仍未开放；这轮交付三项实际生命周期修复及可复用的本地分批检查入口。

首次 MCP/Skills 准备先后核同一目录来源，等待期间的编辑不会被旧候选误认成已加载。候选未发布失败后重新观察来源，完整配置重建后的临时错误即使恢复为原指纹也可重试。坏 Skills 来源仍保留可用的 inline MCP 和核心助手；关闭后的迟到候选不能发布。

主会话或队友已观察到的 Skill 激活失效会持久清除；恢复旧文件后须重新读取。合法指导的预算暂停不删除正文，也不扫描撤销未观察中间变化的其它会话。暂停会话的摘要晚于前台收尾时，现在通过既有前缀核验安装摘要并释放额度，其它会话可继续压缩；不恢复暂停任务或提前改动活动会话的回放。

两名独立实现者分别以旧源码复现 MCP/Skill 问题和暂停压缩占槽；主 agent 复审另外发现坏 Skills 指纹异常会破坏首次启动，以及相同来源恢复漏重试的边界，修后补齐门控。详细反证及单模块证据见[扩展生命周期](extension-lifecycle-review.md)和[压缩收尾](compaction-paused-review.md)。
