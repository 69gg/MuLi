## 发送确认修复

真实临时 outbox 的旧实现反例确认，HTTP 200 的 `ret=false` 被记为 sent，
受限反例在 0.12 秒内失败、峰值 57.4 MiB。固定官方源码同时明确将 `{}`
视为成功，不能用要求 `ret` 必填来修复。

签名实现 `2601745` 已整合为 `e801d59`。只在 `sendmessage` 核验已存在的
`ret` / `errcode` 数值类型，拒绝 bool 和非有限 float；保留省略、有限数值零
及原明确非零拒绝语义。坏回执经既有 uncertain 进入 unknown，不自动重发，
显式重试复用原 client ID 和分段位置，不回显响应正文。poll 与上传不改变。
来源、合同及作者 42 项新增与 53 项既有验证见[发送回执](weixin-receipts.md)。
root 独立静态复审没有剩余 P1/P2。

显式 SILK 语音出站只完成协议研究，未加入本版。SDK 的头部标识和调用者
提供的时长并不证明完整音频有效，TTS 或普通 MP3 不会被伪装成微信原生语音。
