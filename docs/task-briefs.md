# 独立任务说明

任务说明保存一件事的完整目标、要求和已有依据，方便沐璃与队友在长时间协作中核对。已保存的说明独立于聊天摘要，对话压缩或正常重开后仍可查阅。

## 保存和读取

交办较长的任务时，可以直接说：

> 请把这件事的目标、必须遵守的要求和已有资料保存成任务说明，读回给我核对，再交给队友处理。

把重要要求说具体，例如“只读查看”“先交本地草稿”“未经我确认不要发送”。可以引用已经保存的消息或附件，请沐璃记录准确出处。

请核对读回的内容。普通聊天不会保证逐条自动登记，尚未写入说明的要求也不能当作已经同步给队友。

查看正在协作的任务时：

1. 打开团队列表，找到相关队友。
2. 点击“查看任务说明”，核对目标、要求和已有依据。
3. 想检查进度、报告或成果时，请沐璃继续[核查任务](task-inspection.md)。

只有关联了任务说明的队友才显示这个查看入口。没有看到时，可以先请沐璃核对这项工作是否已登记并关联。

<a id="可续元数据目录"></a>

## 查找以前的任务

不知道旧任务 ID 时，可以直接描述你记得的事情：

> 找一下之前整理学习笔记的任务，读回完整要求，并告诉我已有的成果和依据。

沐璃可以查找已保存的任务，再读取准确的说明。一次查询没有找到，不代表所有记录都已查完；有更多页面或遗漏提示时，应继续查找并说明范围。

团队列表用于查看相关队友，不保证一次展示全部历史任务。找旧任务不需要自己编造 ID，也不会因此重新执行旧工作。

<a id="绑定和上下文"></a>

## 把说明交给队友

可以请沐璃把队友与这份说明关联。关联后，队友准备后续工作时会读取绑定的目标、要求和依据；已经准备好的请求可能仍使用原版本，补充后应核对队友是否已经收到变化。

普通任务需要更正时，请沐璃先核对原说明，再保存变化，并明确通知相关队友。说明不会自动广播给所有任务。

**修改说明不会自动暂停队友，也不会撤回已经开始的操作。** 正在处理的工作需要暂停或调整时，使用现有的[暂停、补充要求与继续任务](task-control.md)入口。

先暂停准确任务，再补充要求、交沐璃重新规划。受控任务通过该入口追加要求，保留原目标和旧要求；提交后仍需核对新计划与实际状态。

“已交沐璃”不等于队友已经继续，“新计划已确认”也不等于成果已经完成。遇到结果未知的操作，先核查已有回执和实际成果，再决定下一步。

## 预算、恢复与边界

任务说明与当前输入、必要历史共同受上下文容量限制。容量不足时会明确报错，可请沐璃核对并精简说明，或调整相关设置；不要把报错当成要求已经同步或任务已经继续。

正常重开与对话压缩不会删除已保存的说明、历史修订和队友关联。重开不会自动解除任务暂停，也不会自动批准或重做旧操作。

任务说明、引用资料和队友报告用于协调与核查，不增加操作权限。已有工具审批、文件访问范围和系统权限仍然生效；文件引用也不保证文件以后始终可读。

分工和队友状态见[团队协作](workflows.md)，要求与成果核对见[任务核查](task-inspection.md)。
