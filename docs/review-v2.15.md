# 2.15 原渠道汇报与系统事件查询

状态：候选整合中。独立切片已经实现、测试和复审；整版与远端验证分别记录，不操作用户服务、真实账号或模型。

## 原渠道回复

宿主在插件/模型等待前固定不可变 ReplyOrigin，团队树、持久报告及 ingress 原子交接保留原来源；Store 只认领连续相同完整目的地的 FIFO 前缀，原生工具调用/结果批次完整收尾后再认领下一来源。执行 principal 与任务约束不由回复目的地授权。原渠道不可用持久 blocked，管理重试复用同一记录并重验原目的地；unknown 仍需原有显式确认。

独立静态复审包含核心及 blocked 前端补充，无剩余阻断。新增 23 项与既有 168 项 Python 相关回归通过，最大峰值 170.8 MiB；10 项定向前端通过，峰值 36.9 MiB，均 swap 0。相关 Ruff、格式、6 份产品源码严格类型通过。测试为临时 Store、假模型/HTTP，包含重开恢复；未证明真实账号回复时效或真实进程重启。Workflow、主动默认渠道和记忆选路继续独立推进，不计入本版。

## 系统事件回查

只读查询核对原记录/事件固定字段，通知策略与证据验证分离。整页无效可继续翻页，预算挡住下一合法条目时不越过；精确字符串 ID 保持大整数，retained_only 明确清理缺口。源类型入口及 event 主键点查均有真实 SQL 计划回归。

首轮发现 ANALYZE 后 summary 退到 SCAN o，显式复用 objects_updated 的索引合同修复；候选 CROSS JOIN 固定 events 内层。独立复审通过。32 项新增与既有系统事件、Attention、管理合计 101 项通过，0.70 秒，峰值 94.1 MiB、swap 0；相关 Ruff/格式及 3 源码严格类型通过（峰值 200 MiB）。详细日志正文、原生日志留存增强和全部第三方 logger 覆盖不在本片。

当前整合候选完整 Python **1,937 通过、1 项平台跳过**，37.11 秒，service 39.310 秒、CPU 31.217 秒、峰值 872.7 MiB、swap 0。前端 **259 通过**，2.49 秒、峰值 93.5 MiB、swap 0。Ruff、179 文件格式、78 源码严格类型及 83 包离线锁一致性通过，静态检查峰值 292.5 MiB。
