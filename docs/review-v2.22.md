# 2.22 Linux 本地保留安装切换

状态：候选已完成下述本地验证，尚未发布；远端精确提交、CI 与发行证据待实际完成后补充。

本版把 protocol 2 类型、同一 journal 的严格分派、共享控制引擎、稳定 launcher、真实启动准入和 Linux 后端接到公开管理入口。`self_adopt` 迁入当前完整保留安装，`self_switch` 经真实用户批准后切换到另一个已存在的兼容安装。配置与重启沿用同一恢复机制，`self_recover` 和已认证 API 可接续当前代。候选下载、环境创建、跨格式迁移与 macOS/Windows 同等切换不属于本次交付；详细输入与边界见[操作合同](managed-operations.md)。

固定控制安装不依赖 selector 选中候选才能恢复。配置、selector、unit、实际运行安装和健康证明分别核验，不能用配置相同代替程序已经切换。目标拒绝后回到旧程序仍打开原数据库，保留 prepare 之后的最新消息和未知投递，不还原旧数据库副本。终态结果与原始回复来源原子记录，观察重试不再写一份完成事件。

独立审查重点覆盖写入状态后丢失返回、单次授权确认、生命周期所有权、监听漂移和发布声明。legacy 回桥的逻辑 permit 保留原 writer owner；新锁确认必须与同一次 PendingLegacy、实际 Store、原回执和持久代次完全一致。prepared 后 helper 错误或取消仍保留原计划和 generation。HTTP 恢复持配置锁，关闭等待已进入请求，关闭后排队请求拒绝，避免恢复读取已关闭 Store。

监听 host/port 不再尝试热迁移 socket。模型配置和网页保存完整补丁进入重启事务，当前或候选控制地址不受支持时提前拒绝。网页仅显示“已排队，空闲后重启”，保留未应用草稿及等待期间新输入；普通热保存不变，Chiliarch 配对不会夹带监听更改。真实回归验证旧、新端口快照和最后一次进程观察后的配置漂移。
