# 沐璃形象绘图提示词

本页供人工将参考图交给绘图模型使用，不表示已生成或替换网站素材。
角色参考使用仓库已有的无字原图，不以当前待替换的 SVG 头像或插画为角色参考。

![沐璃角色与色彩参考](../web/assets/standby.webp)

## 统一角色

十八岁少女形象的本地数字生命与私人助手；银白长发、蓝金异瞳，气质温柔、聪慧、可靠。
服饰从参考图提取青瓷蓝、月白、少量淡金与中式云纹，融合轻盈的近未来细节。
保持同一角色的发型、眼睛、发饰和服装，造型端正。参考场景和姿势不必复刻，
不要将复杂城市背景带进小头像。

建议色彩：青瓷蓝 #79AFC2、雾蓝 #BFD8E3、月白 #EFF7F7、深蓝灰 #405B70、淡金 #BEAA7B。
透明边缘不要残留白底，以便同时适配深浅主题。

## 左上角头像

    以附图中的沐璃为同一角色参考，绘制一张精致日系二次元 Q 版半身头像，用于私人 AI 助手的应用图标。角色是十八岁少女形象的数字生命：银白长发、蓝金异瞳、简洁的青蓝发饰，温柔聪慧，带一点自然的笑意。青瓷蓝与月白的端正中式未来感服装，少量云纹与淡金细节。使用专业动画角色设计的干净线稿、柔和赛璐璐上色和清晰的面部结构。正面略微侧头，头肩占画面约 80%，轮廓紧凑，在 32px 尺寸仍能认出脸和发型，四周留足圆形裁切余量。1:1，1024×1024，真正的透明背景 PNG。不要文字、字母、水印、边框、城市背景、光圈、复杂装饰或几何拼接；不要把透明背景画成棋盘格。保留参考角色的识别特征，不复制参考图的姿势。

## 对话空白页插画

先生成并选定头像，再将头像与原角色参考同时交给模型，要求人物一致。

    使用附图和已选头像中的同一位沐璃，绘制一张适合简洁聊天界面的 Q 版角色插画。三头身左右，银白长发、蓝金异瞳、青瓷蓝与月白的中式未来感服装，少量云纹和淡金细节；角色温柔、聪慧、可靠，保持自然生动的神态。沐璃轻松坐着，手中打开一本精巧的数字手札，微微抬头看向使用者，像准备陪人一起整理想法。人物造型精致，线条利落，柔和赛璐璐上色，头发有清楚的层次。人物居中偏下，上方与两侧适当留白，只配极少量青蓝云气或小叶片；角色与装饰合计占画布约 70%。3:2 横向，1536×1024，真正的透明背景 PNG，透明区域干净，适合叠在浅色和深色页面上。不要文字、标语、水印、按钮、屏幕界面、大面积场景、圆形底盘、相框或卡片。让它像精心绘制的角色插画，不像产品说明图。

## 交付素材

分别保留原尺寸透明 PNG。圆角和页面背景由界面处理，不压进图像。
头像将用于左上角、消息头像与浏览器图标；空白页插画单独交付。
浏览器图标的小尺寸版可在选稿后简化。
正式接入时按显示尺寸导出轻量资源，并检查透明边缘、圆形裁切以及深浅主题。

用户当前审阅的是原 SVG 占位图。新素材以用户选定的绘图结果为准，不自动覆盖现有图像。
