## 审查合同

独立 Store 策略默认关闭；预览绑定版本、URL、大小、摘要、策略、实际安装、
原始依赖意图、本地材料及完整格式证据。预览只取有界元数据，真实审批后
重核同一事实。下载默认 8 MiB、最大 32 MiB，实际原始 body、材料和期限均
有限，HTTPX 不采用环境代理配置；系统网络路径不在这个保证范围内。

整个 attempt 使用同一个绝对期限，网络收尾共用既有独立停止期限；所有
owned task 仍须收尾。临时材料从首字节计入预算，先持久 pending，实际
wheel 身份、兼容声明和大小摘要核验、fsync 后才记录 accepted。之后沿
原四步离线准备，不覆盖当前或上一可用安装，不自动重试未知结果。

根审查先发现下载回执保存缺少 SQLite 外层事务与自动提交模式门；作者
补齐真实 Store 的三模式反例。独立尾审进一步发现完整宿主异常收尾仍可能
经 `_finish_plan` 提前提交调用者事务，要求在任何配置文件删除及事件写入
前拒绝，并补完整 `_apply_candidate` 反例。旧链在真实 BEGIN + sentinel
下确定性复现错误提交；修复后的三模式全部通过。根审查与独立尾审再次
确认门位于所有删除/写入之前，不 rollback 或 commit 调用者事务，
`_applying` 仍在 finally 释放，原计划、事件、快照与材料保持。
