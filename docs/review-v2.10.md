# 2.10 已保存正文归档审查

状态：本地实现、独立后审查、真实浏览器、离线发行包与八项发布前矩阵完成；签名标签发行的十一项作业和 PyPI/GitHub 元数据核验完成。本轮只实现已知会话的只读归档窗口及单条正文续读，全目录标题搜索与实时首屏资源改造另案处理。

并行研究与独立反证确认：持久主会话和旧记录保存超过 1000 条消息后，原详情仅返回最后 1000 条，早期原文仍能通过既有 HistoryEvidence 读取。因而本轮解决第一方界面的可达性，不把节选前已经丢失的内容描述成可恢复。另已复现目录越过最近 200 条后不可搜索，明确保留为下一片，不能用正文分页冒称解决全部目录。

设计独立审查纠正了实时回放假设：hydrate 自己拼接 delta/reasoning，依赖 completed 清除旧尾流；删除完成事件会使已完成回复重复出现。全局 SSE 首次连接仍可能从 after=0 回放。首片因此使用独立归档状态与弹窗，不修改实时链路；新增 32000 字符上限也不宣称整个启动、SSE 或内存已经有界。

数据层沿用现有消息证据投影与 UTF-8/JSON 装箱，API 复用认证和错误映射，界面独立请求归属与代次。独立 reviewer 还复现了 JavaScript 对 2^53+1 游标舍入造成漏项，HTTP 和界面将超出精确范围的序号明确拒绝，不增加另一套 BigInt 或游标框架。

核心与 HTTP 首轮整合已通过 88 项归档、正文证据和 API 回归，以及 71 个源码文件严格类型检查。覆盖主/旧会话各 1001 条实际保存记录、1000 字符预算连续读回全部记录、默认大预算的 32000 字符整页上限、NUL/emoji/HTML 原文续读、错会话和版本/删除错误、认证和 GET 前后数据库写入计数不变。这是首轮专项数量，最终本地结果另列如下。

独立 ASGI 后审查分别补核六项和三项门控反证，覆盖响应开始后追加/删除/修改、巨大来源字段的明确省略、精确序号边界和只读无写入。另在已有 SQLite 3.46/3.47 实证极大内部预算使 substr 长度窄化，修为共享内容与四项元数据的实际 BLOB 字节长度上界；三项失败反证修后通过，另一 reviewer 验证普通偏移、空正文和索引语义保留。没有安装旧运行时或改变 HTTP 的 32000 字符上限。

最终产品树本地回归为 1538 项 Python 通过、1 项 macOS 专用冒烟在 Linux 跳过（27.36 秒）；Ruff、153 个 Python 文件格式、71 个源码文件严格类型和离线锁文件检查通过。前端新增 23 项归档门控，整套 197 项通过；导航修改后由另一 reviewer 独立重跑 23 项归档门控。

真实浏览器连接临时 SQLite/ASGI 服务，主身份与旧任务各保存 1001 条消息，从实际入口翻至最早记录。136813 个 UTF-8 字节的长正文经四段读回后与保存内容逐字一致，包含中文、emoji、NUL 和 HTML 文字；只保留当前段。归档打开时通过真实 EventBus/SSE 发出明确模拟的开始、增量和结束事件，聊天继续接收、归档页和草稿保持；未调用模型，也未将这项传输测试描述成真实模型执行。

实测发现长列表底部的导航不便使用，修为顶部导航，主动翻页或换段时将归档滚动区归零。重新加载最终资源后复验主入口、21 页最早记录、手机长正文续读、焦点及控制台。1280×800 桌面与 390×844 手机深浅主题均无横向溢出，导航在内容前且可见。截图：[桌面](screenshots/history-archive-desktop.jpg)、[手机](screenshots/history-archive-mobile.jpg)。旧任务详情及媒体入口仍保留；全目录标题搜索未实现。
