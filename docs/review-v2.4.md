# 2.4 审查与验证

状态：本地集成、独立审查和离线发行包验收通过，等待远端 CI 与发布核验。2.4 聚焦 Linux 的应用/窗口定向读取、准确省略报告、观察刷新与动作凭据的生命周期；不把后续 macOS AX、Windows UIA 研究写成本版能力。

## 设计依据

独立 reviewer 对旧 helper 运行 fake GI 反证：根有 101 个子节点时返回 101/102 个节点；深度 13 的单链返回 13/14 个节点；一个子节点读取异常时返回 1/2 个节点。三种情况旧实现都错误返回 `truncated=false`。测试未导入系统 GI，也未访问桌面总线。

本轮保留系统 Python 单次 helper 和现有可取消进程管理。宿主负责临时标识、当前发现缓存及最终输出预算；helper 负责原生身份复核、定向遍历及确切省略原因。零参数快照保持兼容；未授权的定位参数、过期目标和失败刷新均不能换成名称搜索或恢复旧凭据。

并行对照本地 Codex 后，独立 reviewer 发现异常退出的旧式独立会话先写入新 user、后修复工具尾部，导致旧工具调用长期没有持久结果，压缩无法越过它。真实数据库重开反证中主会话可正常推进，独立入口与复用 `run_step` 失败；现有压缩/上下文/团队 106 项回归通过，说明旧用例没有覆盖该恢复入口。修复把缺失结果的 `unknown` 落盘移到新 user 之前，不重跑工具或覆盖已有成功结果。已形成的历史中段断配不作为本次自动迁移范围。

## 验证记录

最终整合后单进程全量 Python 测试 **1023 项通过**（16.47 秒），前端状态与 DOM **93 项通过**；全仓 Ruff、122 个 Python 文件格式检查、65 个源码文件严格 mypy、离线锁文件校验与 diff 检查通过。无依赖新增或升级。

helper 候选 `14f149eb`、宿主候选 `3f70e99` 均签名冻结。独立 reviewer 验证 helper 正式测试及额外反证 88 项、宿主与实际 helper 的离线组合 59 项、压缩恢复正式及独立反证 8 项；这些与全量测试重叠，不能相加作为测试总数。未发现剩余确定阻塞。

审查修复了有原生身份的桌面根 getter 失败、21 项动作被静默裁剪、editable 与当前状态不一致、省略明细缩水后把小计当作精确数量等问题。公共节点保留相对深度、父引用与父级是否被观察到；实际 fake 树中的同名按钮关联不同面板，预算裁剪没有悬空父引用。

七项独立两层组合反证已纳入 `tests/test_computer_integration.py`，直接使用发行 helper 和 Computer，只用 fake GI 替代桌面 provider、假 subprocess 桥接两者的真实 JSON。它们验证应用发现→窗口→定向快照→动作的完整数据流、不遍历未选应用、当前状态变化拒绝、未知结果只派发一次、Unicode 两层预算及并发发现取消。没有用各自独立的接口桩来冒充两层协议兼容。

真实关闭/重开 SQLite 后，主会话、兼容独立入口及复用 `run_step` 三条续办路径都能先保存一次 unknown，再接收新输入并推进多层摘要；原成功结果保持不变，没有执行旧工具。结构化电脑错误在假模型下一轮、原始工具归档和完成事件中一致保留。配置回归覆盖旧文件、持久化往返、有限正数及类型/范围约束。

候选 wheel/sdist 离线构建通过，在临时目录隔离安装后检查 CLI 2.4.0、静态文件、提示词、API 文档、默认关闭的电脑发现、无模型任务控制和应用生命周期；发行名称、版本及 changelog 一致。没有从远端下载发行包或改动用户安装。

未验证：真实桌面点击/文本设置、Arch GTK/Qt/Electron 各应用支持、macOS AX、Windows UIA。未安装系统依赖、启动真实模型、采集屏幕或更改用户服务。发布需完成集成回归、签名提交、远端 CI 及发行物核验后另行记录。
