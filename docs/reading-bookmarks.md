# 保存续读位置

读资料时，可以对沐璃说：“记住这一页的末尾，下次从这里继续。”之后说“继续上次那份”，即可找回最近明确保存的位置，也可以按文件名查找。

支持普通 UTF-8 文本、PDF 文字层和 DOCX 主正文。网页与已绑定的主人私聊共用同一份位置；对话压缩或正常重开后仍可找回。同一主助手的队友可以查询位置，主助手也可以保存队友实际读过的一页。

普通阅读、队友阅读和按书签续读都不会自动推进位置。需要更新时再次明确告诉沐璃；“清除这份资料的书签”只清除位置，保留附件、对话和长期记忆。

## 文件变化时

书签保存具体文件和正文版本。文件丢失、内容改变或文档提取结果不同，续读会提示无法核对，沐璃不会猜测新位置。可以重新读取后保存，或清除旧书签。

目录和书签查询只读元数据；真正继续阅读时才核验文件。末尾位置只表示所提取文字的末尾，PDF 图片、排版等仍受[文档阅读范围](document-reading.md)限制。

## 相关工具

| 工具 | 用途 |
| --- | --- |
| `reading_bookmark_list` | 最近保存的位置与文件名查询；空结果且 `has_more=true` 时仍需继续翻页 |
| `reading_bookmark_read` | 查看指定附件的位置与代次，不读取正文 |
| `reading_bookmark_set` | 主助手引用已完整归档的阅读页，明确选择页首或下一页位置 |
| `reading_bookmark_delete` | 主助手清除指定位置，保留代次以防旧操作覆盖 |

主助手先通过历史消息工具取得页的消息 ID 和版本；同一工具批次刚读出的页不能立即设置，下一模型轮次即可使用。设置与清除沿用现有 ask、auto、yolo 权限；不增加额外确认流程。

书签不收藏资料、不建立索引、不调用额外模型，也不主动发送消息。需要按正文主题长期查询，仍可明确要求[收藏资料](attachment-memory.md)。
