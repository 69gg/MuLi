# 2.2 审查与验证

本轮以独立任务说明和持久增量等待补足长任务协作，复用原 SQLite、工作账本、原生协议回放和事件通知。详细合同及 Codex 参考边界见 [2.2 连续性说明](agent-continuity-v2.2.md)、[任务说明](task-briefs.md)、[团队等待](team-wait.md)。不增加依赖、模型下载、空闲轮询或默认采集能力。

## 独立审查

任务说明与等待分别在隔离工作树实现，再由其他 agent 复核。审查验证宿主真实调用身份、子协程继承、插件显式替换、压缩与原生回放预算、完成事件原子性、多观察者/多代分页及恢复。Web/API 接线另经独立复核，16 项 Python、8 项前端专项通过。

独立等待实验在 3 个目标、75 次完成、2400 字预算下分 38 页读取，没有漏掉修订；重复旧游标返回一致结果。真实运行时在 1000 字输出预算下取得初始游标，主人输入与完成同时到达时先返回输入，随后仍可读取完成记录。

审查修复的问题：

- 首次无游标结果太长时，通用输出截断可能吞掉游标；模型工具现在明确节选并保留完整基线/游标，Python 接口保持旧快照。
- 合法标题中的 JSON 转义字符，以及近预算的进度字段加上遗漏标记，可能在缩小预算后令主会话读取账本失败；投影从包含标记的最小对象开始计量，标题可节选，原始说明及标题不改。回归先保存旧记录，再热改预算并完成真正主会话调用。
- 详情打开时的实时刷新会替换原按钮，关闭后丢失焦点；现在按队友身份恢复，旧响应及认证失效有单独处理。

## 整合验收

首轮整合通过 745 项 Python、75 项无依赖前端测试，111 个 Python 文件格式检查及 64 个源码文件严格类型检查；账本预算修复后新增两项回归通过。最终发行验收随修复合并继续更新，当前数字不能替代尚未完成的远端检查。

IAB 使用独立临时目录、关闭全部模型与设备，验证详情全文按文本显示（HTML 不执行）、旧任务未登记提示、迟到响应不覆盖新详情、401 清空并关闭详情后登录门可用，以及 SSE 刷新后焦点回到同一队友。390×844 手机尺寸没有横向溢出。临时页面与进程验收后关闭。

测试使用假模型、临时 SQLite、事件门控及真正数据库重开；不调用真实模型，不录音、不截图用户桌面，也不改用户服务。完整说明仍依赖主助手登记；已经构建的模型请求使用当时快照，不承诺发送前刷新或即时撤回工具调用。未登记要求、任意自然语言限制的形式化执行不属于本版保证。
