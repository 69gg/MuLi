# 持续身份迭代复核

此记录对应 v1.0.0 之后的开发分支，不表示已完成 PyPI 发布。各功能先由实现 agent 验证，再由另一位 agent 或主协调者复核组合行为；测试使用临时目录、假模型、模拟 HTTP 与进程，不操作用户账户或桌面。

## 已定位并修复

| 问题 | 修复与证据 |
| --- | --- |
| Windows 默认编码读取中文配置失败 | 配置测试明确 UTF-8；首轮远端 CI 提供失败证据，修复已签名推送。 |
| 可选加密依赖未安装时类型检查失败 | 在加密适配边界明确返回 bytes；用跳过导入解析的类型检查复核 Any 边界，并运行含渠道依赖的加密回归；基础依赖完整环境由远端 CI 验证。 |
| 输出超限后停止读取管道，子进程回收可能挂起 | 终止后有界排空并关闭管道；stdout/stderr 洪流回归使用独立进程 watchdog，避免测试自身无限等待。 |
| 只配一个并行槽时，后台摘要阻塞前台 | 摘要使用独立单请求额度，仍受候选数量限制；阻塞摘要期间的新会话可继续流式输出。 |
| 最后一次流式期间完成的摘要一直占着候选位 | 正常结束和取消的 idle 边界采用 ready 摘要，释放后续压缩额度。 |
| 超预算工具批次挤掉当前任务和原生工具配对 | 执行与写入前整批检查剩余预算；有界历史投影从完整用户轮次开始，不能容纳当前轮次时明确失败。 |
| 异步语义检索返回后重新缓存已忘记的来源 | 查询捕获记忆修订号，媒体锁及 embedding/rerank 等待后复核；变化时返回当前本地投影，不重试网络、不缓存旧证据。覆盖删除、编辑、提炼合并和服务失败降级。 |
| 执行中插入系统资料使 owner 任务提前只读收尾 | 等待活动主任务完整结束后再交付，配置锁内再次核对空闲；等待可单独取消，不取消 owner，原工具批次与渠道回复完整完成。 |
| 渠道验签后等待配置锁时主人授权被撤销 | 在 Runtime.submit 的配置锁内再次校验配置代际和授权快照；失败不进入主会话、不触发模型。 |
| 相同渠道消息 ID 重试时正文与附件被混合 | 下载与断点复用前校验完整信封 SHA256，冲突返回 409；旧记录明确标记无法核验，旧未完成记录拒绝自动复用。 |
| 热改监听配置可能提前取消仍暴露的进程认证 | 以进程实际监听地址判断是否允许清除密码，明确报告需重启。 |
| 截图入口没有检查电脑总开关 | 接线层检查 computer.enabled，后端再检查 capture.enabled；拒绝时不产生附件。 |
| 手动录音未被模块关闭取消 | 跟踪手动、后台、排队采集和合成操作，关闭等待清理；重复取消关闭者也不会跳过清理。 |
| 语音回调内合成回复造成文件锁重入 | 锁外调用转写回调；嵌套操作保留外层取消登记。 |
| macOS 无声录屏可能选择麦克风输入 | avfoundation 明确使用 video:none，非 none 音频选择在启动进程前拒绝。 |
| Windows 服务结束自己后不能重新启动 | 独立临时计划任务完成停止、等待和启动，并清理自身任务。 |
| 更新重新安装可能丢失可选依赖 | 改用 uv tool upgrade；临时微型 wheel 的离线升级实验证明 extras 保留，冲突版本约束会明确失败。 |

## 组合验证

API 测试实际执行应用生命周期、密码认证、签名 webhook、隔离入站、配置热改、附件下载与持久记录。主人从渠道切换至网页后沿用同一身份和历史，网页回复不会广播到旧渠道。纯媒体功能测试使用模拟采集，不打开开发机麦克风或屏幕。

系统注意事项在运行时启动前固定初始游标，接入后台生命周期和热配置回滚。集成测试验证首次历史跳过、启动事件交付、关闭/重新启用、配置重建故障后的磁盘及运行状态恢复、系统主体保留与空渠道路由；独立核心回归覆盖只读执行边界、去重、背压、离线恢复及取消。

chiliarch 0.5.0 使用临时本机服务完成 MuLi 配对、SSE 连接和自我介绍持久化；协议 WS/SSE/长轮询重连与旧消息指纹兼容均有测试。四类外部通讯平台完成请求、签名、加密、文件与故障恢复模拟验证，尚未连接真实账号。

安装包已在独立临时目录离线构建、安装和启动检查，验证网页、CLI、提示词、API 与生命周期。跨平台完整结论仍以各次远端 CI 为准，不能把能力探测或模拟系统命令当作真实系统服务、桌面授权或声学模型联调成功。
