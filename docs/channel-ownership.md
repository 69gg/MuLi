# 让队友接管主人私聊

目前支持 **OneBot 已绑定主人的点对点私聊**。群聊、陌生人和其他渠道暂不支持接管。接管不会增加权限，仍使用现有会话和记忆系统。

先让主助手创建一位直属执行队友，完成准备工作。队友空闲、任务已经正常完成且没有绑定暂停任务后，可对主助手说：

> 把这个 OneBot 接入的主人私聊交给刚才的资料队友。回答先显示在网页；需要外发时再明确调用发送工具。

主助手使用 `channel_delegate`，选择 `action="assign"`、`channel="onebot"`、队友准确 `agent_id`，以及范围：

- `scope="account"`：该 OneBot 接入中原本就允许接收的主人私聊。
- `scope="private"`：同时给出已绑定的 `owner_id`，只接管这位主人。指定私聊的归属优先于接入级归属。

接入级范围不会让原本不允许接收的群或陌生人变合法。队友沿用原来的身份、会话、权限模式与资料；后续消息继续进入这位队友的新一轮执行，正常重启后仍保留归属。队友的回复与完成报告保存在本地会话，主助手可查阅，不额外唤醒或镜像为主助手回复。只有明确调用 `channel_send` 才向外发送，且受托队友只能发送到本批真实发来消息的私聊；主助手仍可明确选择其他已绑定目标。排队不等于送达。

## 查看与归还

主助手可用 `channel_status` 查看当前归属。对原范围调用 `channel_delegate(action="request_return", ...)` 会给队友保存并唤醒一条归还通知；这轮仅能读取现状或归还，不取得新的写入、外发权限。调用 `action="reclaim"` 强制收回。受托队友可用 `action="return"` 归还自己的范围。指定私聊收回后保留“由主助手处理”的例外，不会再次落入接入级接管。

强制收回会撤销该范围旧轮尚未开始的操作与审批，排队输入保留取消记录，不会自动搬到主助手重复执行。已经开始的文件操作或网络发送不能保证追回；未知结果应先查状态。停用渠道、更换账号或主人绑定、改变相关权限模式也会撤销旧资格，之后需重新选择队友。

本片暂不支持受托队友继续派生团队、启动独立工作流或向主助手发内部咨询。需要这些操作时，先明确归还，再由主助手协调。

## 查历史与升级

`channel_history` 仍查询同一份本地收发目录。接收项会标明实际会话 `session_id`，使用该会话与消息 ID 交给 `conversation_read` 读取原文；普通网页回复不混作外发记录。旧平台事件重投保留第一次接收归属，不会因接管或收回再次执行。

这项功能需要新的数据格式。旧数据须停机后按[格式升级说明](channel-ownership-format-upgrade.md)执行固定升级；不能让旧发行直接读取升级后的数据。新装不需要迁移。当前固定升级仅支持满足说明条件的 Linux 独立服务，托管升级流程与其他平台旧库不在此片升级范围内。
