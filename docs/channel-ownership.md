# 让队友接管主人私聊

支持 **OneBot、Telegram、QQ 官方机器人和微信 iLink 中已绑定主人的点对点私聊**。群聊和陌生人不支持接管。WebUI 始终由主助手处理；接管不会增加权限，仍使用现有会话和记忆系统。

先让主助手创建一位直属执行队友，完成准备工作。队友空闲、任务已经正常完成且没有绑定任务说明后，可对主助手说：

> 把这个 OneBot 接入的主人私聊交给刚才的资料队友。回答先显示在网页；需要外发时再明确调用发送工具。

主助手使用 `channel_delegate`，选择 `action="assign"`、对应 `channel`（`onebot`、`telegram`、`qq` 或 `weixin`）、队友准确 `agent_id`，以及范围：

- `scope="account"`：该渠道账号中原本就允许接收的主人私聊。
- `scope="private"`：同时给出已绑定的 `owner_id`，只接管这位主人。指定私聊的归属优先于接入级归属。

渠道、账号和主人共同确定范围；不同渠道使用相同的账号或主人 ID 也互不影响。每位队友同时接管一个范围。接入级范围不会让原本不允许接收的群或陌生人变合法。

队友沿用原来的身份、会话、权限模式与资料；后续消息继续进入这位队友的新一轮执行，正常重启后仍保留归属。队友的回复与完成报告保存在本地会话，主助手可查阅，不额外唤醒或镜像为主助手回复。只有明确调用 `channel_send` 才向外发送，且受托队友只能发送到本批真实发来消息的私聊。省略 `route` 时自动沿用该条消息的完整来源与回复凭据，无需手抄平台消息 ID；显式指定的路由也不能更换它们。主助手仍可明确选择其他已绑定目标。排队不等于送达。

## 向主助手咨询

可以交代受托队友：

> 遇到资料疑问时，先请主助手只读核查，再按我原来的要求继续工作。

正在接管私聊的直属执行队友可使用 `team_consult(question, wait_seconds)` 提问，并在当前轮等待建议。评审队友以及只处理归还通知的轮次不能发起咨询。

普通直属执行队友也可使用同一咨询工具，绑定任务说明时同时核验原任务版本，见[团队分工](workflows.md#向主助手咨询)。接管渠道时仍须核对本批实际接纳的私聊来源，不能切换成普通咨询来绕过归属限制。

主助手忙时先结束当前工作，主人待处理的消息优先。空闲后，主助手只读核查本次问题；回答返回原队友，由它在同一轮继续。咨询不会自动外发，也不能替主人批准操作或扩大队友权限。后续工具仍遵守原来的审批、任务限制和本批私聊来源。

每轮同时只能有一项未回答的咨询，等待时间沿用运行预算。若主助手正等待这位队友而形成互相等待，咨询会被拒绝。超时或主助手回答失败时，原队友收到失败回执；咨询自身失败不会停止其他任务。

咨询期间，主人向主助手发新消息、该队友收到新输入、渠道被收回或相关权限改变，尚未交付的答案都会作废，迟到答案不会重新交付。停止或服务关闭也会结束等待；重启不会恢复未完成的咨询。显式停止主会话或团队仍按原来的范围执行。

## 查看与归还

主助手可用 `channel_status` 查看当前归属。对原范围调用 `channel_delegate(action="request_return", ...)` 会给队友保存并唤醒一条归还通知；这轮仅能读取现状或归还，不取得新的写入、外发权限。调用 `action="reclaim"` 强制收回。受托队友可用 `action="return"` 归还自己的范围。指定私聊收回后保留“由主助手处理”的例外，不会再次落入接入级接管。

强制收回会撤销该范围旧轮尚未开始的操作与审批，排队输入保留取消记录，不会自动搬到主助手重复执行。重复收回或重新委派不会恢复已经撤销的旧轮资格。已经开始的文件操作或网络发送不能保证追回；未知结果应先查状态。停用渠道、更换账号或主人绑定、改变相关权限模式也会撤销旧资格，之后需重新选择队友。

受托队友暂不能继续派生团队或启动独立工作流。需要这些操作时，先明确归还，再由主助手协调。

## 查历史与升级

`channel_history` 仍查询同一份本地收发目录。接收项会标明实际会话 `session_id`，使用该会话与消息 ID 交给 `conversation_read` 读取原文；普通网页回复不混作外发记录。旧平台事件重投保留第一次接收归属，不会因接管或收回再次执行。

收回前尚未归档的排队私聊，可由主助手用 `channel_history(section="ingress", channel=..., owner_id=..., state="cancelled")` 查到原入站 ID，再在同一 section 传 `input_id` 读取中文原文和附件引用，长正文按返回版本与字节位置续读。旧归属证明只说明历史来源，收回后仍可核查原件；被撤权的旧队友轮次不能借 ID 或游标继续读取。读取不会恢复、搬运或重放已取消输入。入站 `delivered` 只表示运行器领取并归档，不代表模型已收到或处理成功；取消也不保证追回已经开始的副作用。

渠道代管需要对应的数据格式。旧数据须停机后按[格式升级说明](channel-ownership-format-upgrade.md)执行固定升级；不能让旧发行直接读取升级后的数据。新装不需要迁移。当前固定升级仅支持满足说明条件的 Linux 独立服务，托管升级流程与其他平台旧库不在此片升级范围内。
