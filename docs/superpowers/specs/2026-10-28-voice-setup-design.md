# 语音设置闭环

本轮把已有声学引擎、主助手和设置页连接起来；不另造 ASR、录音后台、权限系统或配置应用事务。

## 准备配置

主助手新增 `voice_acoustic_prepare`：接收结构化本地模型配置，路径须明确为绝对路径；复用声学配置验证与元数据预检，保存私有、按内容摘要命名的配置快照。返回标准桥接命令与 `self_configure` 补丁，补丁保持 `voice.enabled=false`，准备本身不应用、不录音、不安装或下载。相同内容复用快照；输出预算、文件预算和维护/当前主会话门必须在写入前核验。文件保留在语音私有目录，不发布为附件。

`self_configure` 继续承担审批、排队与实际配置生效。读状态与准备文件不能冒充配置已应用或模型运行成功。

## 有限登记和验证

主助手独立获得设置类工具，不把截图/录屏等执行工具整体开放给统筹。新增明确的 `voice_setup_enroll` 和 `voice_setup_verify`，均走现有 computer 风险审批；只允许后台唤醒关闭时运行。登记保留现有参考保存方法；验证录制最长 15 秒，实际运行唤醒和已配置声纹比对，不调用 ASR、TTS、播放或消息提交回调，不改后台启用状态。两个操作共用现有维护 admission、采集锁、文件配额与取消清理。

缺少录音后端、引擎、必要参考或采样率/设备不一致时，在录音前拒绝。设置状态区分空闲、录音、比对、完成、取消和失败；验证未命中不是执行失败，不会取得主人身份或被当作正式指令。配置重载和服务停止照现有关闭路径结算正在运行的操作。取消只取消这次设置操作，不接管或停止其它正常业务。

## 管理入口

设置页继续显示精简的状态与下一步，可直接请沐璃准备本地配置、登记和验证；已有配置保存是唯一应用入口。为浏览器直接操作提供主人认证、明确确认录音的独立 API，返回真实回执；仅查看状态不录音。所有入口复用同一设置服务，不因 HTTP 绕过维护、禁用工具或单次录音同意。

独立预览使用纯本地模拟回执，明确是预览，不请求麦克风、不启动后端。前端不得显示未经声学运行验证的成功状态；离页或身份改变清除私有回执，取消等待时不能把迟到结果写回新页面。

每次设置具有独立 UUID。HTTP 取消必须携带原设置 UUID，服务端在取消前核对当前操作，迟到的旧取消不能停止新录音；主助手明确使用取消工具时可停止当前设置。前端通过连接所属请求处理鉴权失效，旧连接的迟到 401 不弹出新连接的登录页。

## 验证

离线替身覆盖准备/应用区分、摘要复用、输出预算先于写入、主/队友权限、工具禁用、缺依赖前置拒绝、后台关闭仍可显式有限录音、参考登记、真唤醒与声纹结果、无 ASR/播放/消息副作用、取消与重配置、API 确认和前端迟到响应。真实麦克风、真实模型、显卡不在本机开发验证中触发。
