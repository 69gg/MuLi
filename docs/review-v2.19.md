# 2.19 Linux 同版本恢复入口

状态：本地验证通过，等待候选 CI 与发布核验。本版连接此前分别审查的恢复组件，包含实际 CLI/API 接线；跨版本 A/B 更新仍为后续切片。

Linux serve 在配置和业务数据库之前取得 writer lease，并核验实际 systemd 启动身份。宿主持久保存管理计划代次，再发布 manifest、journal 和候选配置；独立受限 helper 执行排空、停止、CAS、被动启动、健康确认及放行。业务库 WAL/FULL 与终态原子投影保留最新收件、原汇报来源和未知效果，不能通过换数据目录绕过同一个 unit 的未决事务。

独立审查修复了取消后覆盖已准备代次、偏好证据在异步探测后失效、原始服务控制与 prepare 交错、固定 unit 与 caller 数据目录不一致、构造失败提前释放 lease，以及关闭失败仍误判写入者已退出等问题。ASGI 和外层 CLI 共用同一事件循环及幂等关闭任务，固定单 worker；管理诊断不构造 ConfigFile/Store。

CLI/HTTP 独立入口 31 项与身份/初始化 34 项回归分别通过。整合首轮 43 项失败集中于维护中间件调用会创建主会话的接口，以及关闭测试绑定外层 Task 身份；保留既有只读零写入要求，改用有限现有身份查询，测试观察实际锁等待。相关 94 项与 41 项先通过后再执行完整回归。

最终本地 Python **2,632 通过、1 项平台跳过**，47.87 秒，service 50.204 秒、CPU 37.436 秒、峰值 **943.2 MiB**、swap 0。前端 **268 通过**，2.63 秒，峰值 93.2 MiB；Ruff、218 文件格式、94 源码严格 mypy 和 83 包离线锁一致性通过。所有本机检查使用已核验内核预算，单次 1 GiB、共享 2 GiB、swap 0、一个 CPU、有限任务与时间，未提升上限。

最终只读复审再收紧现有主身份标记的读取：SQL 内限制文本类型和 96 字节，不把损坏的大字段整体搬入 Python。新增 5 项无副作用/非法标记回归与受影响维护、HTTP、事件组共 77 项通过，峰值 402.5 MiB；两文件 Ruff/格式及单源码 mypy 通过。该小改后不重复未受影响的全量本机组，干净远端矩阵将验证最终候选全量。

离线构建 wheel/sdist，并在源码树外临时安装验证导入、网页资产、API 文档、提示词、默认关闭的桌面功能、任务控制和 lifespan，安装输出版本 2.19.0。构建峰值 91 MiB，安装验证 88.8 MiB，swap 0。无网络依赖安装或模型下载。

未操作用户真实 systemd 服务，未验证真实停机时长、断电或外部渠道故障；所有副作用使用临时文件、SQLite、fake runner/probe/transport。macOS/Windows 已静态核对导入门，实际远端矩阵结论待 CI。第一期只支持标准同用户 systemd unit、实际 cgroup v2 及本地持久文件系统；能力不足明确拒绝，不自动直接重启。原位 self_update 不获得跨版本回退能力。
