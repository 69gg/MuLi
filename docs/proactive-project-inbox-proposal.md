# 项目资料主动复核：实现合同

日常使用见[资料收件目录](file-inbox.md#跟进一个项目)。本页面向开发与审查；当前实现仍在本地验证，发布状态以 [CHANGELOG](../CHANGELOG.md) 为准。

## 用户行为

主人明确将一个现有 Linux 收件目录关联到一份已保存、有完整要求、尚未结束的任务。新 UTF-8 文件到达后，同一主助手空闲时按需读取当前任务、原附件和新资料，在 Web 留下有出处的复核说明与建议。

事件只给定位，不预注入正文。读取沿主人选择的 ask、auto、yolo；只提供真实风险为 read 的工具，并在实际调用前再次核验。项目复核不自动导入、收藏、改任务、派工、恢复暂停或外发项目报告。固定模型仅用于编排验证，不能证明自然影响判断质量。

## 来源与接纳

- `file_inbox_configure` 和认证 settings API 增加可空 `project_id`，沿完整替换规则保存；省略或 null 解绑。绑定及独立策略原子提交，不扩主配置、工作区或附件权限。
- 未绑定时落盘及签名省略新键，原 generic 来源 scope/revision 与未消费事实保留。此逐条表示兼容不代表旧程序可打开新版整库。
- 来源证明冻结 record/event、scope/revision、binding revision 和准确项目 ID，与真实收件记录同事务保存；不含任务当前版本，不因任务修改重签旧事实。
- 消费时另读当前完整任务快照。在配置锁内最终重核来源、绑定及快照后才保存 receipt、cursor 和 ingress；快照冲突不提交，只允许一次立即重构，第二次等待真实总线变化，不轮询。
- 任务结束、解绑、来源失效终止对应事实，不降级为 generic，也不挡住后续事项；任务暂停仍可只读说明，不解除暂停。
- 来源和批次使用既有字节、数量及窗口预算。绑定前预留完整 canonical JSON，提交前再核真实记录大小；超预算回滚候选与事件，沿原唯一缺口记录暂停。

## 项目段与新主人输入

受信 `attention_project` 随 ingress、首次领取和归档消息保持。项目批次只接纳准确标准 v1 Web-bound 路由；原始路由及 reply origin 的坏值不能被归一化成合法 Web。不同证明和路由证据独立合批，普通 owner 与 generic 合同保持。

`PreparedRequest.project_inbox` 只从本运行实际首次领取的元数据建立，跨请求重建保留。中间、异常、部分和最终消息均保持空外部投递路线；默认主动通知目的地不能改变项目段。

新主人输入仍立即持久排队，保留原内容、主体、渠道、引用和权限模式。工具批及无工具最终流两条分支都不在项目段认领它：当前已发调用完整配对，未开始项明确 not_executed，项目留下“被新输入中断、尚未完成”的本地结果，释放主槽后由独立下一运行处理主人消息。普通 Web 答复保持默认显示；向外部渠道答复仍由 AI 显式调用发送工具。

正常关闭重开、压缩后保留原 proof、seq 和原附件定位；已经接纳的事实不重放。只剩主人 pending 时恢复其原独立运行，不从摘要创建旧项目任务。路径指向当前文件，不能称为到达时的不可变快照。

## 格式与回退

`ingress=5` 包含项目证明的持久投影、独立领取和执行段解释；其余六域保持原合同。精确旧完整 `(1,3,2,4,3,4,1)` 保存为 `PRE_PROJECT_INBOX_FORMAT_STATE`，须沿[既有停机升级](channel-ownership-format-upgrade.md)转换。新装直接使用当前格式；Windows 旧库和托管跨格式升级暂不支持。

真实旧 2.136 运行会丢弃项目标记，并可在项目同一运行认领新主人输入。其 Web 路由发送门仍存在，不能仅凭工具 schema 推断已经实际外发；但它已无法维持项目输入合同，必须在启动与 A/B 同格式判定前拒绝新库。冻结旧源码 reader、manifest 和原字节摘要见[格式边界](fresh-format-admission.md#项目资料复核的格式边界)。不靠文档声明降级缺口、修改 marker 或放宽写格式等式绕过。

## 验证范围

使用临时目录与 SQLite、真实 Linux 文件事件、Runtime、原工具、真实权限流程和受控 HTTP。验证当前完整要求、原附件与新文件确实进入工具结果；覆盖快照竞态、撤销、预算、坏路由、工具回执、三种手机插入边界、压缩重开与幂等。项目零外发断言须等待实际消费者 cursor，主人独立轮的显式答复和审批通知另按准确来源核对。

格式回归须调用冻结旧 reader，验证新旧双方准入、五种构造入口、精确前序停机迁移、业务行与未知回执不变；历史记忆单域反证仍保留。失败先定位，不提高额度、延长门限或跳过用例。

真实模型判断、真实账号送达、用户目录、网络文件系统、真实系统重启和其它平台 watcher 未验。本功能不补扫停机文件，也不承诺恢复未知副作用。
