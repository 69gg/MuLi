# 2.14 扩展与通讯迭代

状态：候选开发中，整版检查、独立复审与发行分别记录；没有切换用户服务或安装新的运行环境。

## 原生语音发送

显式 `media_mode=voice` 通过 Telegram sendVoice 和 OneBot record 发送单个已登记音频附件；默认 file 保留既有路径，包括 QQ 按音频 MIME 发送的旧行为。OneBot 在发送前查询 can_send_record，不支持时不改成文件；支持格式、大小、两次摘要核验及未知结果语义见 [语音渠道设计](channel-voice-design.md)。微信与 QQ 的显式语音模式在当前适配器中不支持，不推断外部协议永远不支持。

独立静态评审未发现阻断；作者通过语音、既有渠道、应用集成与本地服务共 61 项回归，0.99 秒，峰值 121.7 MiB、swap 0；修改源码严格类型、Ruff 与格式检查通过。这些是协议替身结果，没有真实账号收发、ASR/TTS 或设备验收。

## 配置热更新恢复

真实临时应用的三项门控反证确认：关闭某组件抛异常会让已关闭的注意事项组件停留在停止状态；在关闭或重新启动阶段取消调用者会过早释放配置锁。修复把关闭阶段纳入恢复范围，以独立强拥有任务完成应用或恢复，重复取消观察者不取消该任务，也不会释放调用者仍持有的配置锁。

修复前 3 项均失败；修复后与既有应用集成、管理文件合计 19 项通过（0.87 秒），service 1.610 秒、CPU 1.592 秒、峰值 122.1 MiB、swap 0。没有增加休眠掩盖竞争。恢复本身失败仍报错，本片不证明独立进程控制者、硬退出后自动回退或重启中断时长。

独立静态后审查确认重复取消期间保留锁与恢复任务所有权，恢复失败继续传播，无阻断项；Ruff、格式与源码严格类型检查通过。

## 系统事件与关闭边界

独立系统事件模块与旧来源 adapter 等价迁移共 59 项通过，峰值 73.9 MiB；Skills 模块 47 项通过，峰值 72.7 MiB；MCP、目录和相关 Runtime/API 合计 179 项通过，最大峰值 349.3 MiB（类型检查），均 swap 0。上述是作者及独立后审查的分片证据，整合结果另记。

后审查用两个真实临时应用门控反证发现：管理事务在关机中恢复后会重新启动已关闭的注意事项任务；既有 API 配置事务可能尚未结束便关 Store。修复前两项均失败，修复后与原恢复测试共 5 项通过，峰值 89.8 MiB。关机先拒绝新配置、等待管理事务和配置锁屏障，再最终关闭组件，不持锁等待管理 worker。

运行接线与日志读取 25 项通过，峰值 62.5 MiB。另一个单例反证确认 MCP 关闭抛错会留下系统日志消费者；现在最外层保证停采集，只有 driver/finalizer 已收尾才关闭 Store。原异常保留；早期关闭失败不假称全部资源已回收。修复后运行、配置和关闭合计 12 项通过（0.65 秒，service 1.311 秒，CPU 1.297 秒，峰值 95.5 MiB，swap 0）。

## 依赖与隔离

整合后第一轮全量 Python：1,879 通过、1 项 macOS 平台跳过，36.10 秒，service 38.186 秒、CPU 30.132 秒、峰值 855.5 MiB、swap 0；175 文件格式及 Ruff、76 份产品源码严格类型、83 包离线锁一致性通过。离线构建 wheel/sdist，并从源码目录之外临时安装验证导入、网页资产、接口文档、默认桌面行为、任务控制与完整 lifespan，通过且未发现真实用户目录。前端源码和测试与已验证的 2.13 完全相同，本地不重复运行。

冻结前独立审查补出整体 reconfigure 的 MCP 清理归属漏洞：始终关闭失败的旧 manager 会被替换并丢失待清理状态。真实应用反证修前未抛异常；修复使最终 close 尚有未确认连接时抛固定错误，恢复也保留旧 manager，不伪称成功。对应旧测试改为明确断言 shutdown 的错误与待清理数量；该产品变更后的最终检查另记。

最终独立静态复审无剩余阻断。MCP 修复后相关 80 项通过，随后整版 **1,880 通过、1 项平台跳过**，36.03 秒，service 38.140 秒、CPU 30.089 秒、峰值 839.1 MiB、swap 0。该轮没有真实账号、模型、桌面、服务安装或重启。远端矩阵与发行仍待完成，不以本地通过冒充跨平台或已发布。

PR #17 首轮 CI `39452082640` 的核心 quality 环境未安装可选 FastMCP，严格类型检查拒绝从不可用依赖的 Any 类型继承 MessageHandler。本地按导入不可用的类型语义复现，改用锁定版本原生支持的异步 message_handler 回调，并只接受 SDK ServerNotification 中的 ToolListChangedNotification；不为核心安装增加 MCP 依赖，也不关闭严格检查。55 项 MCP/扩展回归通过，峰值 123 MiB；无增量的 76 源码严格检查通过，峰值 376.3 MiB。其它真实平台结果及最后修订另记。
