# 连续导航与对话宽度

设置左侧分组只切换当前内容，保留标题、导航及被点击按钮的身份和焦点；切换前沿原表单收集草稿，返回分组仍能继续编辑。原实现会重建整张设置页并重播入场动画，切换本身并未发请求。本次移除该整页重建与普遍的内容入场动画；显式刷新状态、保存、进入其它管理页面仍使用原请求和权限流程。离开的表单直接丢弃，不缓存额外含凭据的 DOM。

状态刷新及保存后的新草稿也复用设置外壳，只替换当前表单，且不重播分组切换动画。草稿显式清空（例如退出或配对后要求重新读取）、首次进入、加载与读取错误是重建边界；空草稿不会被“已在设置页”的快捷路径拦住。

对话默认正文宽度从 800px 调整为 920px。消息、思考、工具、审批、运行状态与输入框共享一个宽度变量。桌面可以直接按住正文左右边缘拖动，两侧始终以中心对称变化；边缘平时不可见，悬停、键盘焦点或拖动时才显示细线，没有额外按钮。边缘是可聚焦的竖向 separator，支持左右方向键、Home/End；Escape、指针取消或窗口失焦撤回本次未提交的拖动。读屏会获知当前宽度及可用范围。

宽度仅在本浏览器的 `muli.conversation-width` 保存一个数值，不保存账号、资料、提示词或密钥，也不发送服务端请求。桌面偏好范围为 600–1440px，实际宽度还受当前可用页面限制；缩小窗口不覆盖较宽的已保存偏好，放大后恢复。小屏隐藏边缘并按可用宽度排版。存储不可用或数值无效时使用默认值。

主对话默认持续跟随最新内容。审批单独到达、输入框变高、图片等内容稍后完成布局、窗口缩放及正文宽度变化，都在布局后的同一帧合并滚动到底；不再把内容增高误判为用户上翻。一个 `ResizeObserver` 只观察六个固定布局节点，没有轮询或新增请求。

用户滚轮、键盘、触摸或滚动条确实让主区域向上移动时，才暂停跟随；回到真正底部或点击原“回到最新消息”后恢复。流式内容与上滚同帧发生仍保留阅读位置，布局自身产生的滚动不取消跟随。思考区内部滚动保持独立，设置页或尚未显示的零高对话区不会被拉动。

切换主要工作区采用短促位移与淡入，设置分组只对内容做局部过渡，控件沿原色彩体系反馈悬停和按压。流式输出不会反复重播整页动画。启用 `prefers-reduced-motion: reduce` 时关闭这些过渡及原平滑滚动；拖动始终直接跟随指针，不用动画追赶。

实现及回归候选已落盘。13个布局新节点及7个滚动新节点与既有前端合345项通过，守卫3.947秒、95.8 MiB、swap 0。离线 DOM 测试覆盖设置 shell/导航身份、焦点、草稿、零请求及减少动态效果；受控几何测试覆盖两侧拖动、键盘、取消、持久化、缩放与小屏。独立审查发现迟到的旧指针失捕获事件可取消新拖动，先取得1失败7通过的精确反例（126ms、39.4 MiB），再按当前边缘及pointer ID窄修。

滚动首轮先取得3失败9通过：实际审批独立增高、输入区缩小视口及布局产生的滚动都能误失跟随。修正后12项通过；后审又用真实注册事件和原渲染器取得同帧流式增长、聚焦控件PageUp两项精确失败，以及短工具结果PRE上的实际主区域上滚反例。最终15项对话回归通过（守卫275ms、57.2 MiB、swap 0），原思考内部滚动负控保持。测试仅控制浏览器几何和帧调度，没有替换生产渲染器，也不代替真实浏览器滚动验收。

原预览的两小时服务已经到期，已在同一 `http://127.0.0.1:51123/` 启动新的纯静态预览；内核核验128 MiB、swap 0、CPU 25%、32任务及共享slice，寿命仍为两小时，未启动真实后端。滚动后修再次核验同一服务实例、内核限额和HTML、布局模块、app、样式、预览入口的精确字节及no-store响应；没有打开浏览器页面。本轮回归不代替真实像素布局、触摸设备及辅助技术验收。
