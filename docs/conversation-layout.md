# 连续导航与对话宽度

设置左侧分组只切换当前内容，保留标题、导航及被点击按钮的身份和焦点；切换前沿原表单收集草稿，返回分组仍能继续编辑。原实现会重建整张设置页并重播入场动画，切换本身并未发请求。本次移除该整页重建与普遍的内容入场动画；显式刷新状态、保存、进入其它管理页面仍使用原请求和权限流程。离开的表单直接丢弃，不缓存额外含凭据的 DOM。

状态刷新及保存后的新草稿也复用设置外壳，只替换当前表单，且不重播分组切换动画。草稿显式清空（例如退出或配对后要求重新读取）、首次进入、加载与读取错误是重建边界；空草稿不会被“已在设置页”的快捷路径拦住。

对话默认正文宽度从 800px 调整为 920px。消息、思考、工具、审批、运行状态与输入框共享一个宽度变量。桌面可以直接按住正文左右边缘拖动，两侧始终以中心对称变化；边缘平时不可见，悬停、键盘焦点或拖动时才显示细线，没有额外按钮。边缘是可聚焦的竖向 separator，支持左右方向键、Home/End；Escape、指针取消或窗口失焦撤回本次未提交的拖动。读屏会获知当前宽度及可用范围。

宽度仅在本浏览器的 `muli.conversation-width` 保存一个数值，不保存账号、资料、提示词或密钥，也不发送服务端请求。桌面偏好范围为 600–1440px，实际宽度还受当前可用页面限制；缩小窗口不覆盖较宽的已保存偏好，放大后恢复。小屏隐藏边缘并按可用宽度排版，输入与原滚动逻辑保持。存储不可用或数值无效时使用默认值。

切换主要工作区采用短促位移与淡入，设置分组只对内容做局部过渡，控件沿原色彩体系反馈悬停和按压。流式输出不会反复重播整页动画。启用 `prefers-reduced-motion: reduce` 时关闭这些过渡及原平滑滚动；拖动始终直接跟随指针，不用动画追赶。

实现及回归候选已落盘。13个新节点与既有前端合338项通过，守卫3.783秒、93.9 MiB、swap 0。离线 DOM 测试覆盖设置 shell/导航身份、焦点、草稿、零请求及减少动态效果；受控几何测试覆盖两侧拖动、键盘、取消、持久化、缩放与小屏。独立审查发现迟到的旧指针失捕获事件可取消新拖动，先取得1失败7通过的精确反例（126ms、39.4 MiB），再按当前边缘及pointer ID窄修。
