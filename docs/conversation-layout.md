# 调整聊天布局

聊天中的回复、思考、工具、审批和输入框使用相同的宽度。桌面上可以按住对话左右边缘直接拖动，无需打开设置；宽度偏好只保存在当前浏览器。

默认宽度为 920px，桌面可在 600–1440px 之间调整，实际显示仍会适应窗口。缩小窗口不会覆盖原偏好，放大后会恢复；小屏幕自动使用可用宽度。

边缘也支持键盘操作：聚焦后使用左右方向键调整，Home / End 选择最小或最大宽度。Escape 取消本次拖动。

## 跟随最新消息

没有主动向上滚动时，聊天会持续跟随最新内容，包括流式回复、工具结果和新出现的审批。

向上滚动后，页面保留你的阅读位置。回到底部，或点击“回到最新消息”，即可恢复跟随。思考内容可以在自己的区域内滚动。

## 页面过渡

设置分组切换时保留页面框架和未保存的草稿，仅切换当前内容。主要页面使用简短过渡；系统开启“减少动态效果”时关闭相应动画。

更多使用方法见[工作台](frontend.md)。
