# 2.21 新资料库格式准入

状态：本地整合验证已通过，准备签名候选与远端矩阵；尚未发布。完整跨版本 A/B、稳定选择入口和候选安装仍未交付，本版不宣称可以自动降级或恢复数据库。

实际 Runtime 工厂现在只为本次独占创建并完成初始化的资料库写入完整格式标记。构造锁覆盖创建、三组初始化、主身份及最终标记发布；已有空文件和历史库不获得创建证据。再次启动先核验标记、合同和身份，配置与扩展发布等待之后也复核。普通插件私有表保留，不能由此推出插件副作用已受认证。七领域合同与失败边界见[格式准入](fresh-format-admission.md)。

独立复审修复了创建路径在 SQLite 连接前被替换的写入窗口；二进制主键和大小写等价表名也不能把已有标记伪装成缺失。最终单模块包含 44 项回归，使用真实子进程争抢构造锁、临时 SQLite 和失败注入；没有接触真实用户资料库或系统服务。

自更新与新准入一起封闭：已标记资料库在缺少目标版本格式证据时不能走原位安装。生成计划之前、发现 uv 之前及工具目录等待之后均检查，拒绝不创建新计划或运行安装器。`self_status`、管理 API 和新版提示共享实际能力；损坏标记仍可读取固定诊断。旧未标记库保留原有安装检查，不将用户批准或版本号大小当作兼容证明。

全量回归发现的旧夹具已按实际行为调整：只读接口同时验证 fresh/legacy，保留完整会话快照、零写入、精确分页和禁止模型调用；启动关闭 spy 改为真实 `Store.open_runtime`，保留数据库关闭早于 writer lease 释放的全部断言；旧原位更新队列显式使用 legacy 库，不屏蔽格式门。

最终 127 个后端测试文件通过统一 guard 分四批串行执行，共 **3,118 项通过、1 项平台跳过**，service 59.494 秒、峰值 922.3 MiB、swap 0。前端 **268 项通过**，service 2.540 秒、峰值 94.8 MiB。未增加单次 1 GiB、共享 2 GiB、单 CPU 等效预算或 180 秒期限。先前失败批次止于第一处失败，修复后才重新验证。

全仓 Ruff、236 文件格式检查通过。一次增量 mypy 报告既有 YAML 导入注释 unused-ignore；没有修改源码或降低严格模式，无缓存复核 101 个源码文件通过（7.308 秒、383.8 MiB），随后普通增量检查同样通过。局部测试与最终全量分别记录，不累计当作唯一测试数量。

83 包离线锁一致性、2.21.0 wheel/sdist 离线构建、源码树外临时安装 smoke 和发行元数据核验均通过。构建峰值 91.1 MiB，安装 smoke 峰值 89.4 MiB，swap 均为 0，没有下载依赖。安装后验证了导入、网页资产、API 文档、提示词、默认关闭的桌面功能、任务控制与 lifespan，CLI 输出 2.21.0；本地产物不上传，正式发行仍使用远端该次检查的构件。

精确候选 CI 与正式发布结果在完成后追加。Windows/macOS 的构造锁已按官方接口语义独立静态审查，实际平台执行仍以该候选远端矩阵为准；模型、外部账户、真实服务控制与桌面操作不在本轮验收内。
