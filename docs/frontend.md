# 使用网页工作台

启动沐璃服务后，在浏览器打开服务地址即可进入工作台。有访问密码时先登录。本文说明当前实现的界面；可用入口以所安装版本、配置和权限为准。

## 持续聊天

首页是一段持续的主对话。可以直接输入需求，让主沐璃统筹工作，并查看队友、工具与结果。

- `Enter` 发送，`Shift + Enter` 换行。
- `Ctrl/⌘ + K` 返回主对话。
- 正在处理时仍可发送补充要求；页面会显示实际排队状态。
- 停止按钮用于请求停止当前工作，已经开始的外部操作不保证能够撤回。结果未知时应先核查，不要直接重做。

切换管理页面会保留当前对话和未发送的草稿。刷新页面会恢复已保存的消息与当前真实状态，但未发送的文字草稿不会跨刷新保存。

正文、思考和工具调用放在同一条中央时间轴里。工具完成时更新原位置；展开工具块可查看参数、结果和错误。“未执行”“失败”和“结果未知”含义不同，不能只凭一条完成动画判断外部操作成功。

## 阅读与调宽

主对话默认跟随最新内容，审批出现、输入框变高或页面布局变化时也会保持底部。实际向上滚动查看旧消息后停止跟随；滚回底部或点击“回到最新消息”即可恢复。

思考区过长时在内部滚动，查看思考不会关闭主对话跟随。工具详情可以保持展开，后续状态更新不要求重新打开。

较宽屏幕上，可以直接拖动中央对话的左侧或右侧边缘，两边对称调整。思考、工具、回复和输入框共享宽度。边缘获得键盘焦点后，左右方向键调节宽度，`Home` / `End` 选择当前可用的最窄或最宽值；拖动时按 `Esc` 取消本次调整。

宽度偏好只在当前浏览器保存，不包含聊天内容。缩小窗口时会自动限制到可用空间，小屏不显示拖动边缘。

## 查看和处理审批

需要人工决定的工具会出现在主对话，也可以从“通知 → 待批准”查看主助手和队友的等待事项。

批准前核对实际会话、运行、工具、风险、参数和请求原因。批准只是允许这一项请求继续，不等于工具已经成功；拒绝则阻止尚未开始的调用。提交期间等待服务端确认，不要根据按钮变色推断结果。

主人在主助手等待审批时补充新要求，可以使旧主调用作为未执行收口，再按新输入继续规划；队友各自等待的审批不会因此被一并批准或撤销。已经进入执行阶段的操作不能靠补一句话保证追回。

如果页面重开后显示旧工具“结果未知”，可查看原记录和实际目标确认情况，不会自动重放旧调用。已绑定的私聊渠道也可使用手机审批命令，见[渠道说明](channels.md)。

## 附件、图片与语音

通过附件按钮上传文件，或从“附件”页面选择已有文件带入对话。文件先保存在本地附件库，消息引用其附件 ID；从输入框移除引用不会删除文件。

图片、音频和视频可在支持的格式下预览，其他文件提供下载。媒体不会自动播放。上传不等于已经读过正文、识别图片、转写录音或收藏长期记忆，需要明确提出相应要求。

上传 PDF 或 DOCX 后，可请主助手或队友按需[阅读正文](document-reading.md)；不需要把全文复制到聊天框。

也可以在“附件”页面点击某一份文件的“收藏”，核对读取范围和正文预览，再确认收藏到长期记忆。支持完整 UTF-8 文本、PDF 文本层和 DOCX 主文档正文；预览标有“还有后文”时并未显示全文。收藏不发送聊天消息，不覆盖未发送的草稿；后台整理可能使用已配置服务，“已排队”仍需等待后续整理。

关闭弹窗不会撤回已发出的收藏。如果收藏回执中断，重开后先点“核对结果”。核对只确认这份准确资料当前是否已登记，不会自动重发；确需再次主动收藏时，点“重新准备”并再次确认。已登记资料可直接“核原文”，继续使用现有的“带资料提问”。

看图需要主模型声明视觉能力，或配置独立视觉模型。显式保存的视觉说明可继续查阅，但模型解释不是主人确认的事实。收藏文本或文档正文见[长期记忆](memory.md#收藏附件正文)。

网页录音默认关闭。启用网页语音、配置 ASR 并授予浏览器麦克风权限后，可录音生成可编辑的文字草稿，仍须点击发送。取消、离页或退出会停止相关录音流程；详见[语音使用](voice.md)。

主对话里已保存且完整结束的答复，可在最后一段点击“生成语音”。配置 TTS 和音色后，确认把整条答复发送给已配置的语音服务并保存附件；完成后手动播放或下载，不影响聊天草稿。失联不自动补合成，再次主动生成须重新确认且可能重复计费；详见[答复生成语音](voice.md#网页答复生成语音)。

进入语音或桌面采集设置不会自动开始录音、截屏或录屏。在“语音与采集”可让沐璃协助配置，或明确确认一次参考录音、唤醒与声纹验证；后台监听须保持关闭，验证不会提交聊天消息。操作期间可取消；离开该分组、页面隐藏或退出会结束本次网页设置流程，迟到结果不会更新其它页面。组件存在、配置完整和实际系统权限是不同状态，应按页面提示分别确认。

语音设置里的“后台监听”显示最近实际状态，单纯预检可用仍为尚未验证。后台故障可通过通知由沐璃说明；“最近正常”不证明 GPU 运行、声纹准确或远端平台送达。

消息渠道里的 Telegram、微信另有“后台接收”状态，成功接收并保存进度后更新；没有新消息也可通过一次成功长轮询确认最近正常。OneBot、QQ 回调渠道不按消息安静时长推断在线。

## 管理已有工作

从设置入口可以进入相关管理页面：

| 页面 | 可以做什么 |
| --- | --- |
| 团队 | 查看队友、报告与子任务；在“我的任务”翻阅已保存目标，核对完整要求并带回聊天草稿 |
| 工作流 | 管理步骤与依赖，查看结果、取消运行，带原资料回对话继续分工；按需展开定时委托 |
| 记忆 | 查询条目、浏览来源及整理状态、核查原文、更正内容、处理冲突和遗忘资料 |
| 通知 | 分页找回旧通知、核对保存原文并带回聊天，查看待批准事项，管理提醒 |
| 附件 | 预览、下载本地文件，带入聊天或确认收藏正文 |
| 运行记录 | 按标题查找主对话与子任务，翻阅已保存的正文 |

定时委托通过对话创建。列表显示下次时间、最近执行和暂缓状态，可手动刷新或取消；取消不承诺撤回已经派发的外部操作。

主助手安排的普通工作流结束后，可在详情点击“带资料继续”。它将准确引用追加到原聊天草稿，保留附件与待处理语音；发送后再由沐璃核对完整原文并安排新工作，详见[带着原资料继续](workflows.md#带着原资料继续)。

“团队 → 我的任务”可按状态主动翻页，不依赖任务是否关联队友。展开说明后，“带着任务提问”只追加准确引用到原草稿，保留文字、附件和待处理语音，由你检查后发送；不会自动继续任务。保存的任务状态不等于当前执行状态，详见[查找以前的任务](task-briefs.md#查找以前的任务)。

“通知 → 收件箱”按保存的创建时间和通知 ID 分页，能找回最近窗口之外的旧通知。选择全部或未读后，手动翻阅较新/更早一页；新通知只提示有更新，点击“刷新通知”从首页查看，不会把正在阅读的旧页顶掉。缺少时间、已读状态或来源时会明确显示未记录；坏记录、超过预算的记录会列入本页遗漏说明，空页仍可能有后页。

“核对原文”只读取这一条准确通知，长记录需手动继续读取，收齐同一版本后才显示完整正文与主要操作；可展开“来源与完整记录”核对准确 ID、版本及已保存的来源定位。版本改变时须重新核查。“已保存的完整记录”保留原 JSON 文字；来源序号等数值以完整记录为准，草稿保留准确 ID、版本与文字来源定位。原提醒可能已经改期或删除，保存的渠道偏好也不证明平台送达。“带着通知提问”追加准确通知 ID、页面核查版本与来源定位到原聊天草稿，保留文字、附件和待处理语音，由你检查后发送；沐璃会先用 `notification_read` 核对保存原文，再按需核查原约定。

侧栏徽标只统计最近通知窗口（最多 200 条）的未读及当前待批准事项，不是全库未读数。“本页标为已读”仅作用于当前页的明确未读项；查看目录、原文或原会话不自动标读。已读是阅读标记，不表示任务已处理、验收通过或渠道已经送达。纯前端预览的通知与来源均是本页内存示例，刷新页面会重置，不连接真实提醒或消息渠道。

“记忆 → 来源”可以筛选整理失败的资料，按需核对原文，并确认重试这一份。长原文可按段继续阅读；空页仍显示“继续翻页”时，表示后面还有来源。重试回执为已排队时，应刷新查看后续状态，不能视为已经完成。详见[来源目录](memory-sources.md)。

“查看正文归档”只读取已保存的消息，不调用模型、恢复任务或重新发送结果。长正文按段读取；如果记录本身曾被节选，归档不会补回未保存的部分。关闭窗口、离开当前页面或重新登录后，旧读取失效；重新建立工作台连接时也会关闭旧记录窗口，须重新打开核对。记录中的来源与旧工具输出也不会成为新的执行授权。

“设置 → 消息渠道 → 最近发送记录”中的“查看发送内容”可选择当前已绑定主人的私聊，核查本地保存的实际外发正文和准确附件引用。记录分页显示，长正文按窗口翻阅；平台已确认的分段数不表示已读或播放，`unknown` 仍可能已经发出。核查与刷新不会调用模型、自动重发或改动聊天及设置草稿；状态变化后手动刷新，绑定改变后重新选择。读取失败会明确显示错误，详见[渠道发送内容核查](channels.md#网页核查发送内容)。

“已取消”表示这条投递此后不再被领取，保存的正文和附件引用仍可核查，页面不提供重发或取消操作。平台确认 `0/N` 不代表过去从未外发，也不表示已经撤回平台消息；需要取消待发送的准确投递时，可在主对话中向沐璃说明。

## 设置与主题

设置按分组切换，标题和左侧导航保持原位，不需要每次重建整页。分组切换保留当前设置草稿；退出登录、换连接或重新加载配置可能重置草稿，重要修改请及时保存。是否需要进一步应用或重启，以实际回执为准。

常用设置包括模型、称呼与提示词、权限、工作目录、MCP、消息渠道、语音、媒体服务和访问控制。主模型配置好后，其他常规模型角色可留空继承；协议与必填项见[模型与媒体服务](providers.md)。不要把 API 密钥填写到模型地址里。

左下主题按钮切换明暗模式。首次未选择时跟随系统，手动选择后仅在当前浏览器保存偏好。页面动效尊重系统“减少动态效果”设置。

### 查看已注册工具

在“设置 → 权限与工具 → 已注册工具”中，可按名称或用途搜索、按工具来源筛选，点击“查看参数”核对风险、审批要求和完整参数 JSON。这里展示当前服务已经注册的工具；当轮模型实际能调用哪些工具，还取决于会话、角色、当前输入和权限。

MCP 工具显示已记录的服务器和远端工具名，通用 MCP 接口单独标注；插件只标记实际登记的工具。没有来源记录时显示“来源未记录”，不会推断成内置工具。可通过“MCP 与 Skills 设置”或“本地插件设置”前往原配置分组。

工具开关先修改设置草稿，点击原“保存设置”才提交；已保存状态与草稿状态分别显示。搜索、筛选、查看参数或跳转配置分组会保留草稿，不自动保存。保存后重新读取目录，核对实际启停状态。

详情是对当前工具的一次观察，不是历史参数快照。工具被替换或目录发生变化时，请按提示刷新目录，再重新查看参数。目录或详情超出显示预算，或工具名、参数含已知受保护信息时，会明确拒绝读取，不显示残缺 JSON；读取失败也不会显示成空目录。搜索无结果只表示没有匹配项。

## 确认可用状态

纯前端预览只用于体验界面，示例模型、队友、渠道和服务操作是模拟数据，不能据此判断真实服务已经连接或操作已经完成。README 首页动图展示此预览中的输入、审批与流式结果；开启“减少动态效果”时显示新版静态图。真实使用时应查看服务状态、审批回执与实际结果。
