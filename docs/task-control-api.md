# 任务控制管理接口

本接口随 2.3 提供，不属于 2.2 的能力。领域合同见 [任务控制](task-control.md)，执行保障见 [运行边界](task-control-runtime.md)，整合及发行验证见 [2.3 审查](review-v2.3.md)。

管理接口沿用密码认证、同源请求、JSON 请求体及现有请求大小限制。控制来源和持续主会话身份由服务确定，客户端不能提交 `principal`、`session_id` 或 `approved_epoch` 等字段。`expected_epoch` 必须是非负整数，不接受布尔值或数字字符串。

## 读取当前状态

`GET /api/commitments/{id}` 返回完整账本、任务说明，以及当前 `control` 和 `scope`。详情保留计划正文 `control.plan`；列表和写操作的返回投影只含紧凑状态，不把全文广播到每个团队成员。

`scope` 提供 `member_count`、`active_workflow_count`、`can_pause` 与 `blocked_reason`。范围由服务端计算，覆盖绑定该账本的全部队友及后代，不受网页分页影响。`workflow_active` 表示有活动工作流，当前版本需先停止它或等待完成；暂停请求不会只暂停一部分再报告成功。

## 暂停与交主沐璃重新规划

`POST /api/commitments/{id}/control` 接受两种明确操作：

```json
{"action":"pause","expected_epoch":0,"request_id":"这次操作的稳定标识"}
```

```json
{"action":"request_replan","expected_epoch":1,"request_id":"另一次操作的稳定标识","additional_requirements":"只读核查，保留原文件"}
```

暂停不需要模型配置，也不自行创建重规划输入。`request_replan` 要求任务已经暂停；补充文本完整追加到原要求，空文本表示按现有要求重新规划。没有主模型或入站容量不足时，原暂停和原要求保持原样。

`request_replan` 还可提交可选的 `additional_attachment_ids`，将现有 `/api/uploads` 已保存的附件加入原任务依据。该字段复用已有严格附件 ID 列表：小写 32 位十六进制 ID、列表不能重复，并沿用原数量上限；省略或空列表保留原行为。新引用按选择顺序追加并跳过原任务已有附件，完整目标、原要求和旧引用均保留。附件不可用时整项请求失败；`pause` 不能夹带非空附件列表。

成功响应为 `{receipt,current}`。`receipt` 是该操作原始回执，`current` 是返回时的 `{id,revision,control,scope}`。重复同一请求不重复追加要求或入站；较新操作发生后重试旧请求，仍返回原回执与最新投影。不能把旧回执的 epoch 当成当前状态。

网页以账本 `revision` 单调接收状态；同一 epoch 的计划确认也推进 revision。紧凑响应缺少 `plan` 或 `brief` 正文不表示删除，需读取详情补齐，不能将旧正文标为新修订。请求断线后复用原 `request_id`、epoch、完整文字和原有序附件列表确认结果，不自动生成另一项操作。相同请求已提交后，即使附件后来删除也返回原回执；同一标识更换或重排附件列表会报内容冲突。

## 可恢复的错误

控制领域错误使用 `detail: {code,message,current?}`；`message` 用于显示，`code` 用于判断，能够读取当前事实时附带 `current`。

| 状态 | 常见原因 | 客户端处理 |
| --- | --- | --- |
| 400 | 纯空白请求标识、暂停夹带要求或附件、附件不可用、完整上下文超出配置预算 | 修正请求；原事实不变，不当作部分成功 |
| 401 | 尚未登录或认证过期 | 清空控制详情和草稿，回到登录门 |
| 403 / 415 | 非同源请求 / 非 JSON 写请求 | 修正请求，不重试为新操作 |
| 404 | 账本不存在 | 停止该操作 |
| 409 | epoch 冲突、请求标识内容冲突、尚未暂停或存在活动工作流 | 读取当前事实，保留未提交草稿 |
| 422 | 字段类型、取值、附件 ID 列表或额外身份字段无效 | 修正请求，不当作提交成功 |
| 429 | `queue_full`，重规划入站没有容量 | 既有暂停保持，等待后重试 |
| 503 | `model_unconfigured` 或领域事实暂不可用 | 显示具体原因；未配置模型时先配置，任务仍暂停 |

无法确认提交结果的网络错误或不明确的服务错误，不能推断成功或失败。网页关闭不恢复任务，模型的一句“已恢复”也不是确认记录。

接口回归使用临时数据库和本地 ASGI 请求，覆盖认证、跨站请求、严格类型、原回执与最新投影、队列满原子失败、主人来源、计划全文及工作流冲突。主模型运行、任务停靠、最后工具边界和通知恢复由独立运行器测试验证；不能用 HTTP 200 代替执行保障。
