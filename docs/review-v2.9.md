# 2.9 工作流生命周期与活动入口审查

状态：本地整合、真实界面验收、独立后审查与离线发行包验证通过，待精确提交的远端矩阵，尚未发布。本轮限定工作流范围；运行记录的全历史搜索分页留待后续，不改正确的团队 active_only 分页。

先只读对照 `/data1/codex` 的 agent registry/control、mailbox 等待和压缩代次校验。可借鉴的是将持久身份、当前执行和精确父子归属分开，不能把显示历史页当作运行登记表；MuLi 已有这些身份与事件基础，无须复制 Rust 框架或新建通用状态机。此次参考不代表 Codex 的内存 mailbox 具备跨进程恢复保证，也未把已有不占模型槽的 wait 和摘要代次校验重复算作新功能。

真实 Runtime/WorkflowEngine 加门控假模型的临时 SQLite 反证共六项：无额外历史时完成、取消和崩溃快照恢复三项通过，增加 10000 条较新终态记录后三项失败。旧活动运行被 `Store.list(...,10000)` 在筛状态/parent_run_id 前截掉，导致父任务漏等、漏取消、重启后没有 task 却仍 busy；数据库快照来自实际在途执行，未强杀用户服务。独立 reviewer 复现相同结果。

管理 API 也被全局最近 200 条历史限制：真实活动句柄还在，列表却没有它，删除定义仍返回成功。离线 DOM 则证实同一定义最近一次完成会遮住更早的活动执行及停止入口。两者分别有无历史和 active-first 对照，不能靠提高常量或只让一条活动项排首位解决。

实现使用状态/精确父 run 优先筛选、稳定 ID 页和窄元数据投影；定义删除用全范围存在性检查。界面使用独立全局活动页，保留现有最近历史与精确取消接口，不一次性加载全部活动正文。故障恢复只校正状态，不自动重做未知副作用；旧父停止不能碰同会话新一代工作流。父任务仍等待和核对每个子结果，只在输出预算内累积文本；跨三页且预算已满后的末项失败也必须使父任务失败。

独立后审查另以真实父运行、工作流和 ASGI API 复现迟到取消：子成功已落盘、最终事件尚在收尾时，停止请求把 completed 反写为 cancelled，使父运行报失败。无迟到请求的对照通过，带请求的用例失败。修复在首个等待前检查持久终态；已终态只等待驱动任务，未完成运行共享一次取消清理。调用方的重复取消不打断收尾，关闭流程也等待同一清理；首次调度前停止由清理补齐状态。

六项正式回归覆盖真实父链、HTTP 迟到停止、重复停止、观察者取消和首次调度前关闭，修改前五项失败、一项对照通过，修改后全部通过。另一 reviewer 的三项门控检查确认：首次调度前的节点清理仍 queued 时，真实 TaskControl 拒绝暂停；最后 cancelled 发布期间已无节点执行，允许暂停不产生模型或工具调用。取消与关闭同时收养同一驱动任务时，真实收尾错误向观察者传播且映射回收，没有未观察异常。`active_run_ids` 保留实际驱动任务的语义，不把所有持久终态或独立发布操作泛化为活动执行。

真实 IAB 连接两个独立临时实例：第一个实例的两个同定义运行都进入真实 WorkflowEngine 回调后，再写入 201 条较新历史和定义；旧定义不在最近列表中，活动页仍显示两个完整 ID。网页停止第一项后，API 与界面均只保留第二项，再停止第二项后才显示没有活动。另一个实例增加明确命名的 51 条小型模拟摘要，验证 50/3 显式分页；这些摘要没有执行句柄，不能作为 53 个真实 agent 的运行证明。第二页期间通过真实取消 API 终止一项门控任务，SSE 使页面回到首页；另一项仍运行时，在真实网页删除定义收到 409，错误、定义和活动项均保留。

390×844 和 1280×800 的浅深布局无横向溢出，完整 ID 与停止按钮可用；控制台无错误。保留[桌面活动页](screenshots/workflows-active-desktop.jpg)与[手机活动页](screenshots/workflows-active-mobile.jpg)。两实例的模型、渠道、更新、插件、设备与主动关注均关闭；仅节点回调等待本地事件。两个临时进程、页面和视口覆盖已回收。迟到响应等竞争窗口由离线 DOM 门控验证，不声称在真实浏览器覆盖全部时序。

最终单进程全量回归为 1480 项 Python 通过、1 项 macOS 专用冒烟在 Linux 跳过，耗时 25.05 秒；174 项前端测试、全仓 Ruff、149 个 Python 文件格式、71 个源码文件严格类型、JavaScript 语法和 83 包离线锁文件检查通过。所有反证使用小型临时记录与假回调，没有创建万级协程、请求模型、操作外部账号或触碰私人数据库。发行包与远端发布证据继续补充，未通过的阶段不计为完成。

wheel/sdist 使用现有构建环境离线生成，wheel 无依赖安装到临时目录后从源码树外导入。实际安装包验证 CLI/版本、网页资源、文档、默认关闭桌面操控、任务控制和生命周期；随后用真实工作流与门控回调核验 201 条较新历史不遮住活动 API、运行中删除定义为 409、成功后的取消保留终态、活动页清空及历史结果留存。包内版本、发行名和 changelog 一致，无新依赖下载或真实模型请求。
