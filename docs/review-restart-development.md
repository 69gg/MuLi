# 可恢复管理开发验证

状态：开发中。版本范围以完成的产品接线、独立复审和验证为准，设计文档及基础模块不计作已经可用的服务能力。本轮不修改用户服务、真实账号或模型配置。

## 管理事务基础

纯 journal 和可注入 backend 的单步控制器已签名接入，复用已审的[分片设计](restart-transaction-v2.15-design.md)。固定 inode 的 journal 锁与 writer lease、持久化屏障、精确配置快照、同代 CAS、截止期限、一次回退和健康／放行证明均由临时文件与 fake backend 验证。

独立审查修正了目录同步失败后继续执行、旧实例归属、等待后的期限复核、回退实例放行以及错误标记与放行证明冲突时的优先级。首片作者与复审确认的 60 项定向覆盖，在合入 2.15 产品基线后再次通过，0.23 秒；2 份源码严格类型检查通过。该次共用 cgroup 守卫的 service 时间为 1.073 秒、峰值 121.5 MiB、swap 0。

首片当时没有真实服务 backend、恢复 CLI 或完整维护门接线。上述单片测试不证明真实服务能自动恢复、不证明停机时长，也不包含 A/B 安装、下载或数据库回滚。后续接线证据在下面分别记录。

主动默认渠道独立纳入 2.16；本文件只保留尚未交付的跨进程恢复证据。对应版本的发布记录与本开发状态分开维护。

## Linux 只读服务观察

新增 [Linux 后端观察](linux-transaction-backend.md)，复用标准 unit 与有界子进程执行器，核对结构化 systemd 属性及实际 `/proc` 身份；不启停服务、不发布配置或声称 writer 已退出。35 项 fake 回归、严格类型和独立静态审查通过，最终峰值 67.6 MiB、swap 0。此处记录的是观察模块初次交付状态。

## Bootstrap、控制者与入口整合

安装身份、配置 CAS、Linux 控制后端、实际 helper 资源探测、终态投影、本地文件系统验证及启动保护均已分别审查并签名合入。各模块的定向证据保留在对应设计文档；控制者独立于主服务，创建接受与健康/完成证明分开。

宿主现将预分配 generation 先写入 WAL/FULL 管理计划，再发布 manifest 和 prepared，最后请求 helper。审查发现 helper await 期间取消会用旧对象覆盖 generation，现从持久计划和当前 journal 重新绑定；不将已准备事务降为普通失败。偏好证据在最后 await 后重新验证，覆盖排队及探测期间遗忘。

入口独立回归首轮 29 项通过，峰值 130.8 MiB、swap 0。CLI 身份及初始化另 34 项通过，峰值 76.3 MiB：调用者换 data 目录不能操作同一个固定 unit；status/recover 不打开配置或业务库，所有早退前核 manifest 路径。API 原始服务动作在同一配置锁中复核维护门，再使用相同 journal guard。

构造/关闭审查促成单事件循环及单 worker 入口。Store 构造失败先关闭 SQLite；Runtime 或 app 构造失败由拥有者清理。Web 服务在 lifespan 前失败也等待共同关闭任务。关闭失败不能让外层把 app=None 误认为没有写入者：完成所有权交接后，只有实际 writer 能交还 lease；构造失败且无法证明关闭时保留到进程退出。

目前整合 72 项管理、维护、CLI/API 与持久策略回归通过，2.18 秒，service 3.253 秒、峰值 194.8 MiB、swap 0；11 文件 Ruff/格式、8 源码 mypy 通过，类型检查峰值 192.6 MiB。完整整合回归和最终复审尚在继续。测试使用临时数据库、假服务探测和 fake runner，没有操作用户真实服务、网络账号、模型或桌面；真实停机时长和断电恢复未验证。

2.19 候选的完整整合发现并修复维护中间件误建主会话的回归：原有事件位置、历史目录和非法请求测试继续要求零写入，改为仅对主人消息 POST 查询现有身份标记。关闭测试改为观察实际配置锁等待，保留提前关闭数据库的反证，不再绑定外层调用者 Task 身份。相关 94 项与 41 项回归先通过；最终 **2,632 通过、1 项平台跳过**，47.87 秒、峰值 943.2 MiB、swap 0。前端 **268 通过**，峰值 93.2 MiB；218 文件格式、Ruff、94 源码 mypy 和 83 包离线锁一致性通过。首次全量的 43 个失败有明确修复记录，未提高资源限制或修改只读合同。发行状态继续记录于 [2.19 审查](review-v2.19.md)。
