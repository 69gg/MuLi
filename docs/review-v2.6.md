# 2.6 证据续读审查

状态：本地全量回归、独立数据层和真实请求复核、离线发行安装通过；远端矩阵与发布核验尚待完成。

## 缺口与设计

只读参考本地 Codex 的消息定位、正文窗口和持久记录/模型视图分层，发现已有 `conversation_read` 的两处边界：首条长消息超过预算时仍整条返回，通用工具预览会同时吞掉中段与末尾游标；普通工具的过长输出则在消息入库前已被节选，不能承诺新读取器能找回未存尾部。

复用现有消息索引、只读权限和 `conversation_read`，增加有界目录、单条 `content` 的 UTF-8 字节续读、宿主版本及来源标记。SQLite BLOB 切片绕开 TEXT 函数在 NUL 处的限制，Python 不为本次读取加载无关图片与协议块。读取是资料，不恢复旧授权，不复活原工具调用。完整合同与不覆盖范围见 [证据续读](history-evidence.md)。

实施前通过 Context7 核对 SQLite `json_extract`、BLOB `substr/length`、NUL 行为及 Python JSON Schema 2020-12 验证接口；未安装模型或新增依赖。数据层、上下文保留和宿主接线分开实现，再进行独立反证。

## 后审查修复

- 目录二分正文时，如果 `content_truncated` 从 `true` 变回 `false`，最终 JSON 多一个字符，可再次触发通用预览。每个候选现在同步重算完整字段，最终复核外层预算；精确小预算和正常最小 1000 字配置都有回归。
- 最终上下文仍可能节选一个合法证据页。宿主 `preserve_output` 属性仅保护紧邻下一模型请求的完整工具批次，包含同批多页；旧批次可正常移出，system/developer 资料不提前解除保护。伪造返回 JSON 或仅复用工具名不会取得保留属性。
- 直接由受信本地扩展缩小配置预算时，handler 返回与 `tool.completed` 的异步边界之间可能让原来合法的页超限。完整结果工具现在返回有界 `output_budget/result_omitted` 错误，不交付半截分页 JSON、不重跑调用。标准网页配置仍拒绝活动任务期间重配，自身管理等空闲应用；没有声称普通设置页面允许热改。
- 消息的索引归属与 JSON 会话归属必须一致。标准保存拒绝将相同消息 ID 搬到另一个会话；读取仍核对旧损坏记录。任务控制的原有伪造来源测试改为明确的直接 SQL 故障注入，保留读时拒绝断言。

数据层独立 reviewer 运行 41 项正式测试加 3 项额外反证，覆盖精确 Unicode/NUL 重组、目录前进、来源完整保留或具名省略、事务回滚、真实修改失效及不展开图片。另一个 reviewer 在真实工具回合和模型请求路径验证三协议完整页、末尾 context hook、孙代读取旧主人/系统消息后仍需当前写审批，以及输出预算改变的门控；这 6 条已正式纳入回归。上述数量与全量重叠，不相加。

wheel/sdist 已离线构建，临时安装通过版本、模块导入、网页资源、接口文档、提示词、电脑默认配置、任务控制和服务生命周期检查；发行元数据与 CHANGELOG 一致。没有升级用户安装或启动实际服务，最终发行物以远端验证后的同一产物为准。

主会话、独立会话、动态团队和工作流分别在真实关闭/重开 SQLite 后读到已经压缩的旧工具结果中段，原工具执行次数仍为一次。上下文、三协议回放和历史来源均保持实际宿主角色；页面的字节范围不会冒充包含被省略的中段。

未验证：真实模型是否总能合理选择证据、长期真实个人档案的检索质量、真实外部账号和桌面。没有新增全历史搜索、向量索引、历史 ACL 或无限原始输出归档；直接绕开宿主修改 SQLite 不在版本保证内。平台、渠道和原生设备原有未实测边界继续适用。
