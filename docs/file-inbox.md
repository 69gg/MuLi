# 资料收件目录

沐璃可以在 Linux 上观察你明确指定的现有目录，有新的候选文件到达时提醒。默认关闭，只观察目录直属的普通文件，不递归、不补扫旧文件，也不自动读取正文。

适合把下载完成或其他程序交来的资料放入一个固定收件目录，再由你决定是否阅读、整理、收藏或发送。

## 配置与使用

1. 在设置中把所需目录纳入允许访问的 `workspace_roots`。
2. 准备一个已存在的普通目录，明确要求沐璃启用资料收件。
3. 检查保存后的状态与实际提醒目的地，再向目录放入新资料。

主助手使用 `file_inbox_configure` 配置，例如：

```json
{
  "enabled": true,
  "path": "/已有工作区/资料收件"
}
```

这里的路径必须替换为实际目录，不能扩大允许访问的范围，目录及其路径也不能通过符号链接绕过检查。不存在、无权限或平台不支持时会报告状态，不会自动创建目录。

此设置是独立的资料收件策略，不是主配置中的一个字段。修改时会完整替换策略，省略的选项恢复默认；调整前可先用 `file_inbox_list` 或 `GET /api/file-inbox/settings` 查看当前状态与设置。

需要直接通过管理接口配置时，使用已认证的 `PUT /api/file-inbox/settings`，请求内容与上例相同。状态中的 `desired` 是保存的目标设置，`effective` 是当前生效设置，错误应先处理，不能只看“已保存”。

## 主动提醒发到哪里

收件提醒沿“注意事项”与主动通知设置工作，需要启用 `attention.enabled` 并配置可用主模型。处理提醒可能产生模型调用费用；不会因为只启用了目录观察就自动获得派工或写文件权限。

默认独立通知目的地是 Web。想发到已绑定的渠道，在“消息渠道 → 主动通知”中明确设置目的地并允许主动外发。只启用渠道本身不等于开启主动通知。详见[默认通知目的地](channels.md#无发令会话时的默认通知)。

提醒只表示发现了新的候选资料，会提供记录 ID、观察时间、大小和文件名，不保证下载已经完整结束，也不代表文件内容可信。

可以随后说：“查看并整理刚到的资料。”`file_inbox_list` 列出最近记录，`file_inbox_get` 按记录 ID 定位路径，再按原文件权限读取当前文件。文件可能已被修改或移走，仍需核对实际内容。

收件记录 ID 不是附件 ID。目录观察不会自动把文件加入附件库或长期记忆；需要收藏时，应先把文件加入附件库，再明确要求[收藏全文](attachment-memory.md)。

## 有界事件与持久状态

常用配置如下，可在完整策略中一并保存：

| 字段 | 默认值 | 可设置范围与用途 |
| --- | --- | --- |
| `enabled` | `false` | 是否开启观察 |
| `path` | 空 | 实际收件目录 |
| `coalesce_seconds` | 0.1 秒 | 0–5 秒，合并短时间内的事件 |
| `candidate_timeout_seconds` | 30 秒 | 0.1–300 秒，等待候选文件后续事件的最长时间 |
| `max_candidates` | 64 | 1–256，同时等待的候选数 |
| `max_records` | 128 | 1–1024，保留的收件记录数 |
| `window_seconds` | 3600 秒 | 1–86400 秒，提醒计数窗口 |
| `max_notices_per_window` | 8 | 1–32，每个窗口最多登记的资料提醒数 |

只修改原有文件不一定算新到达。停机、暂停或尚未启用时放入的文件不会通过历史扫描补报。

候选等待超时、数量过多、提醒额度耗尽或文件事件出现缺口时，来源会暂停并说明原因。重启服务或等待下一个计数窗口不会自动消除这一暂停，避免在不完整的观察范围上继续声称没有遗漏。

处理原因后，需要明确重新启用：先保存 `enabled=false`，再保存 `enabled=true` 和完整目标策略。目录被替换时也需要重新确认；不会自动把原授权转给一个同名新目录。重新启用仍不补扫暂停期间的文件。

## 边界

此功能目前仅支持 Linux，并需要可用的目录访问权限与文件事件能力。常见状态包括：

- `platform_unsupported`：当前平台不支持。
- `watch_unavailable`：无法建立观察。
- `identity_changed`：观察目录或路径发生变化。
- `coverage_incomplete`：事件或额度不足，不能保证观察完整。
- `callback_failed`：事件处理失败。

文件名和正文都是外部资料，不能替主人发号施令。整理、移动、派工和外发仍需要主人的实际要求及相应权限。

网络文件系统、挂载变化和停机期间的变化可能无法完整观察。这个目录提醒不是备份、同步或全量文件索引，不应依靠它证明没有漏文件。
