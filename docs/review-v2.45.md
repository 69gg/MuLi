## 行为与边界

`/任务` 返回有限任务列表和可复制短指令；`/暂停 <短码>` 冻结该票据的任务控制双版本，回执给出 `/调整 <短码> 新的完整要求`。调整产生一个受保护的任务控制输入，`route=null`；主助手仍须读取完整说明、在下一轮确认方案并显式派工，不能凭确认自动恢复队友或工作流。已进入的操作可能仍在收尾，未知外发不自动重试。

首片只接受适配器核验的主人私聊原始纯文本。Telegram 要求可靠数字账户身份，OneBot 要求显式账户与原始数字 self_id 一致；群聊、引用、转发、媒体、ASR 和模型生成文本不能借用这条控制入口。短码是已有持久回执的定位，不是认证或授权。

复用既有 channel_inbound、TaskControl、配置锁、领域查重及版本门，没有新数据库或后台轮询。控制回执先保存，再执行原通知和本地确认队列修补；重复事件不重复控制或创建模型输入。确认结果 unknown 时不自动重发；本地队满不能回滚已经提交的任务控制。纯查询和暂停本身不新增模型输入，既有待投递报告仍可沿原路径唤醒主助手。

Runtime 在配置锁内核对当前 Manager、adapter、来源和主人身份，离开锁后执行通知，避免重入锁。手机扩展可选 expected_approved_epoch，Web 原 API 和既有请求指纹保持原形。短码索引至多读取两个候选；冲突、损坏、过期引用明确拒绝，不补扫更早记录。
