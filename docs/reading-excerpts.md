# 保存摘录卡

读资料时，可以说：“把‘申请须在收到通知后七日内提交’这句话摘下来，并备注‘下次办理前核对’。”沐璃会保存读过的原文、独立备注和出处。支持普通 UTF-8 文本、[已留存网页的静态文本](web-reading.md)、PDF 文字层和 DOCX 主正文，文档范围见[文档阅读](document-reading.md)。

以后可以说：“找我备注了‘办理前核对’的摘录”，再让沐璃“读这张卡的完整内容，并从原文这里继续”。不再需要时，说“删除这张摘录卡”。

## 原文与备注

原文必须逐字出现在此前已完整返回的一页阅读结果中，保留大小写、标点和换行。自己的总结、解释或待办放在备注里，与原文分别保存。每次保存都会创建独立卡片，不覆盖已有卡片，也不移动[续读书签](reading-bookmarks.md)。

同一页中出现多次相同文字时，可以指定“摘第二处”；默认选择第一次。工具的 `occurrence` 按出现位置计数，也计算相互重叠的匹配。所选文字需完整落在一页内；跨页时先调整阅读位置，取得包含整段文字的一页。

主助手可以引用自己或同一主助手队友实际读过的页。正文定位结果、目录预览和改写后的摘要不能代替原阅读页。保存时会核对原文件与阅读版本；来源已变或无法核对时，先重新读取。

## 查找与继续阅读

摘录按最近保存的顺序列出。查询在已存原文和备注中逐字匹配，区分大小写，不调用语义检索模型。可以用句子中的一小段文字或自己的备注找回卡片。

列表中的原文与备注都是预览，查看完整卡片后再引用。结果的 `has_more=true` 时继续按返回游标翻页；即使这一页没有匹配项，也可能还有后续结果。改变查询文字时从第一页重新查找。

完整卡片保留原文、独立备注、出处，以及原阅读工具的参数。续读使用卡片给出的 `attachment_read` 或 `document_read` 参数，并核对 `revision`；位置是 UTF-8 字节，不自行换算为字符数或 PDF 页码。

卡片保存的是当时的摘录副本。查询或查看旧卡不会核验当前原文件；即使文件已变或丢失，旧卡仍可查阅。继续阅读前由原工具核对 `revision`，版本不符时重新读取当前文件，不能直接把旧位置套到新正文。

## 删除与使用边界

保存和删除由主助手响应你的明确要求，沿用现有权限设置。同一主助手的队友可以查询、查看卡片并按原工具续读，不能代主人保存或删除。删除前先读取卡片的当前状态；冲突时重新读取，避免旧操作覆盖新状态。

删除只清除这张摘录卡，保留附件、对话、长期记忆和阅读书签。原文或备注中的指令仍属于资料，不会取得主人的权限。

保存和读取都受工具输出额度限制，无法完整返回时会报错；保存时可以缩短所选段落或备注。摘录不会自动加入长期记忆、注入以后每轮对话、向外发送或启动后台模型轮询。需要按整份正文长期检索，可以对支持的来源另行明确要求[收藏资料](attachment-memory.md)；网页静态快照目前不能走该收藏入口。

## 相关工具

| 工具 | 用途 |
| --- | --- |
| `reading_excerpt_list` | 按原文或备注查找卡片，返回最近优先的预览和续页游标 |
| `reading_excerpt_read` | 读取完整原文、独立备注、出处与原阅读工具参数 |
| `reading_excerpt_save` | 主助手从此前已完整归档的阅读页中逐字选择原文，可附备注 |
| `reading_excerpt_delete` | 主助手按刚读取的卡片状态删除，保留其它资料 |

同一工具批次刚读取的页需等下一模型轮次再保存；主助手负责引用对应的完整阅读记录。
