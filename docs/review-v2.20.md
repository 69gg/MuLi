# 2.20 升级准备与恢复验证

状态：候选，尚未发布。跨版本 A/B 更新仍未开放；本版提供有界证据和禁止迁移的内部构造，保留现有同版本恢复与原位更新路径。未来托管模式必须与稳定修复入口一起交付，不能提前改变已有用户的启动合同。

兼容声明逐项比较七个持久语义领域；SQLite 读取器在单一快照里核验完整标记与主人主会话身份，拒绝共享缓存脏读连接。它不认证发行来源，也不为历史库生成完整格式标记。禁止迁移构造覆盖 Store、Memory、ChannelManager 和渠道重新配置；普通初始化复用同一份 DDL，缺少必要结构或身份时禁止入口不补数据。成功核验后仍允许合法业务写入，实际启动准入尚未接入。

固定 uv receipt 解析保留原安装意图；安装内采集绑定已核 manifest、固定路径和文件身份，变动使证据失效。`intent_parsed`、`receipt_observed` 仍要求完整上下文，不能据此启动候选安装。独立复审修复了超长 TOML 整数泄漏非固定异常，以及共享缓存连接可以读到未提交格式标记的问题。

真实临时子进程回归覆盖控制者被杀后的锁释放与保守接管，以及收到激活回包后死亡、第二个控制者仅以 writer lease 和 nonce HTTP 收敛。后者不重复激活、不延长期限，原渠道和未知工具结果保留，双次终态投影只有一个完成记录。测试未操作真实 systemd 服务或用户数据库。

诊断方面，`self_logs` 区分真正空文件和因行边界全部省略的结果；渠道状态补全自主扩展监听的独立通知来源。旧 probe 测试夹具的 Tool 参数修正后，明确验证新消息优先造成 `not_executed`，没有改变运行器执行顺序。
