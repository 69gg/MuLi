# 2.36 MCP 普通资源审查

状态：实现、两层审查与根整合检查完成；精确远端验收与发布待完成。

## 用户行为

具有资源能力的 HTTP/SSE 服务器提供 `mcp_resources_list` 和 `mcp_resource_read`。
agent 先按需列出元数据，再通过已展示的引用读取完整短文本，沿既有外部工具审批。
不在启动、提示词或后台预取，不自动把 URI 解释为本机路径或另一次 HTTP 请求。

完整目录只在当前连接保存一份，按既有页数与目录字节预算完成后才发布；宿主
分页维持有限引用。新目录成功发布、换代和关闭使旧引用失效；Skills-only 更新
保留原连接。资源专用服务器不再收到不支持的 `tools/list`。

文本只允许完整交付或固定错误，经过实际 Runtime 打包与模型协议验证。
模板、订阅、二进制正文和 stdio 资源不在本片范围。服务端分页并不保证远端数据
跨页一致；已接纳读取继续持原连接收尾，不承诺自动重试或永久缓存。
