# 使用指南

第一次使用，从 [README](../README.md#开始使用) 安装并运行 `MuLi init`。常用设置可以在网页中调整，也可以直接请沐璃协助。

## 日常使用

- [工作台](frontend.md)：聊天、审批、附件、主题与设置。
- [模型](providers.md)：连接服务、推理参数、视觉和检索模型。
- [个人记忆](memory.md)：自动整理、检索、收藏沐璃的完整答复、核对原文与遗忘。
- [来源目录](memory-sources.md)：浏览已保存资料、定位整理失败的来源。
- [资料变化](source-comparison.md)：核对两份已收藏正文的增删改动。
- [多 agent 协作](workflows.md)：分工、工作流和查看进度。
- [任务说明](task-briefs.md)：保存完整要求，在网页查找旧任务并带回对话。
- [任务控制](task-control.md)：暂停任务、补充要求与继续。
- [任务核查](task-inspection.md)：查阅要求、成果和已有依据。
- [上次工作记录](continuations.md)：重新打开后核查队友与主助手保留的中断记录。
- [长对话](context.md)：自动压缩与历史查阅。
- [找回历史原文](history-find.md)：按记得的文字定位旧消息或工具结果。

## 文件、电脑与语音

- [连续终端](shell-sessions.md)：保留目录和环境、查看长命令进度与停止。
- [队友附件](teammate-attachments.md)：把文件、图片和录音交给队友。
- [附件检索](attachment-search.md)：查找已保存的附件。
- [正文定位](attachment-find.md)：在一份资料里找文字，再阅读命中处。
- [文档阅读](document-reading.md)：按需读取 PDF、DOCX 和长正文。
- [网页留存](web-reading.md)：明确保存公开网页的完整静态文本，之后离线或换渠道续读。
- [续读书签](reading-bookmarks.md)：明确保存位置，压缩、重开或换渠道后继续阅读。
- [摘录卡](reading-excerpts.md)：明确保存读过的原文、私人备注和续读出处。
- [收藏资料](attachment-memory.md)：将附件或已有完整 ASR 转写明确加入长期记忆。
- [长资料检索](memory-chunks.md)：后台分块、续接与索引设置。
- [电脑操作](computer.md)：应用、窗口和无障碍操作。
- [平台支持](platforms.md)：后台服务、截图和录屏。
- [语音](voice.md)：录音、转写、合成与可选唤醒。
- [本地声学引擎](local-acoustic.md)：让沐璃协助接入已有模型，关闭后台也可登记和验证。

## 消息与提醒

- [通讯渠道](channels.md)：接入聊天平台、收发文件与手机审批。
- [chiliarch](chiliarch.md)：配对与接收任务。
- [提醒与主动事项](attention.md)：提醒、任务复盘和定时委托。
- [话题提醒](topic-reminders.md)：下次提到指定文字时，在网页提醒一次。
- [桌面通知](notifications.md)：在桌面接收提示。
- [资料收件目录](file-inbox.md)：接收新资料，或关联任务主动复核。

## 扩展与维护
