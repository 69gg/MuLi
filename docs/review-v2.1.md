# 2.1 交叉审查与验证

本轮分别实现团队管理、网页录音草稿、Wayland Portal 截图，再由其他 agent 审查并整合。实现提交使用有效 GPG 签名；三个功能不增加默认运行依赖。

## 已修复的问题

| 问题 | 修复与回归 |
| --- | --- |
| 旧团队管理只列最早 100 位队友，新队友在长期运行后消失 | 新建优先、服务端分页和进行中筛选；105 位队友验证三页 50/50/5。模型工具的旧排序保持兼容。 |
| 管理摘要先解码大量完整消息和原生图片块 | SQL 直接读取限长 UTF-8 预览，空内容和多字节边界有回归；完整历史不修改。 |
| SSE 与翻页请求交错覆盖新页面，重新渲染丢键盘焦点 | 共用请求代次，按动作、队友及会话身份恢复焦点与展开状态；末页禁用按钮退到标题。 |
| 录音器意外停止后停留在 recording，退出登录残留输入草稿 | 意外停止取消并回收全部轨道；退出登录先取消，再清空内存草稿。假录音器覆盖迟到权限、迟到转写和中途输入。 |
| ASR 请求断开、配置重载或关闭时遗留工作 | 操作登记、取消与等待清理；HTTP MockTransport 覆盖上游取消，限额满时立即拒绝，不建立隐形队列。 |
| Portal 请求未注册时首次 Close 失败，真实 handle 随后返回仍无法关闭 | 失败退出进行中集合，真实 handle 确认后允许补发一次；私有 D-Bus 用事件驱动顺序复现，不靠固定短睡眠。 |
| 截图取消需要远端 Close，但强制终止不留清理机会 | 仅 Portal 启用 TERM 宽限，然后强杀；排空输出与关管道有期限，原有输出洪流回收回归保留。 |

## 验证证据

- 整合树本地：696 项 Python、74 项前端测试通过；Ruff/格式检查通过，63 个源码文件严格 mypy 通过。
- `uv lock --offline --check` 通过，锁文件只更新项目版本，依赖未变。离线 wheel/sdist 构建及临时目录 wheel 安装验证 CLI、静态资源、提示词、状态 API 和应用生命周期通过；发行名称、版本和 changelog 一致。
- 内置浏览器：团队 50/50/5 分页、3 位进行中筛选、下一页按钮焦点和末页标题回退均实测；390×844 手机视口没有横向溢出，页面控制台无错误。对话页保持青瓷蓝和深浅主题，录音按钮默认不可用，设置入口能看到独立网页录音选项。
- Portal 测试只连接临时私有 D-Bus 和 fake 服务；网页录音测试只使用假轨道与 MockTransport，没有打开真实麦克风或采集桌面。

真实 GNOME/KDE Portal 授权与 Documents/FUSE 路径、实际浏览器麦克风权限、第三方 ASR 尚未实测。Windows/macOS 的真实设备行为也不以跨平台单元测试代替。远端检查与正式发布以对应提交的流水线结果为准。
