# 在资料里找文字

可以直接说：“在这份说明里找‘退款’，读第二处的上下文。”沐璃会先定位，再按需读取，不必先收藏资料或逐页寻找。主助手和资料队友都能使用。

支持普通 UTF-8 文本、[已留存网页的静态文本](web-reading.md)、PDF 文字层和 DOCX 主正文。查找按原文字面匹配，区分大小写，保留重叠位置；不使用正则、模糊匹配或 Unicode 归一化。PDF 没有文字层时无法搜索图片中的字，详见[文档阅读范围](document-reading.md)。

## 继续查找与阅读

对应工具是 `attachment_find(id, reader, query, revision?, offset_bytes=0, limit=20)`。助手选择普通文本的 `attachment_read`，或 PDF/DOCX 的 `document_read` 作为阅读视图。

结果只含命中坐标、正文版本和原阅读工具的参数；需要上下文时再读取。`has_more=true` 时，保留查询文字与版本，按顶层 `next_offset_bytes` 继续；位置是 UTF-8 字节，不能自行换算为字符数或页码。

文件或正文版本变化时会明确报错，不能把不同版本的结果拼接起来。查找不会自动收藏、更新书签或发送资料；要日后续读，先实际阅读，再明确要求[保存位置](reading-bookmarks.md)。

每次查找、续查以及随后阅读都会重新校验文件。PDF/DOCX 每次都会重新提取完整的有界正文；查找减少逐页输出，不缓存转换结果。文件过大、转换器不可用、超时或最小结果放不进输出额度时会报错，不把未完成查找说成“没有匹配”。
