# 2.8 多来源别名与召回路径审查

状态：本地验收和独立复审通过，待精确提交远端矩阵与发布。沿用现有 SQLite、查询缓存、证据分页与界面核查，不增加运行依赖、模型请求或全库提炼。

旧唯一别名索引只保存首份来源。真实 SQLite 反证发现：两条独立原文都支持 `Lumi → MuLi`，忘记首份来源后剩余事实和规范名查询仍在，但别名的两跳召回丢失。新贡献表保留各事实登记，删除时只撤销相关贡献，再从仍有效依据修复路由；同源多事实不计为独立来源。迁移只保存旧库真实可知的一份，无法恢复旧版未记录的支持者。

后审查进一步复现旧 source-only 索引加入新贡献后，遗忘新来源会误删旧索引生命周期的问题；修复为保留尚无对应已登记贡献的旧路由引用，只有原引用实际消失后才由剩余贡献接管。补充 source-only、无引用和不一致旧行的保守迁移、两种删除顺序及最终清理回归。事实更正、底层整份替换、规范自名和 legacy 兼容分别验证，不把修复前的测试数量当作最终结论。

路径使用实际 BFS 的父边和方向，每个图命中携带入口登记、事实/来源引用及同一 revision。独立检索命中不补造链。模型工具和融合 HTTP 查询按完整 JSON 保留整条候选与路径，预算不足明确省略；管理列表仅给新增路径设置共享限额，保留原管理行为。缓存与投影分离，网络等待期间遗忘后重新取本地当前快照，不重新请求模型。

原文预览此前先读取整篇再截取；现在在 SQL 侧取有界 BLOB 窗口，复用 UTF-8 边界处理。NUL、中文、emoji、实际来源身份和精确截断标记均有定向覆盖，完整原文接口仍保留原语义。

网页只按需展开一条实际路径，使用原查询重新核查；路径变化清理快照但不影响来源无关的原文详情。首次读取、查询切换、关闭、退出登录和迟到事件使用独立请求代次；引用核查关闭后回到原步骤，失效后有可用焦点落点。真实浏览器发现原生 `replaceChildren` 将条件布尔值渲染为 `false`，修复为只传真实节点，补充先红后绿回归；既有测试替身没有隐藏布尔语义，旧断言漏掉了尾节点。

最终本地 1427 项 Python 测试通过、1 项 macOS 专用 CF/ABI 冒烟在 Linux 跳过，157 项前端测试通过；全仓 Ruff、146 个 Python 文件格式、71 个源码文件严格类型、离线锁文件和差异检查通过。独立 reviewer 检查数据迁移、两种遗忘顺序、旧索引生命周期、BLOB 预览和查询预算，并复跑针对性反证；这些数量与全套覆盖重叠，不另行累加。

真实浏览器连接临时 SQLite/回环服务，完成别名到两跳路径、反向箭头、登记与末步原文核查、关闭焦点、遗忘第一来源后路径失效和剩余依据重查、遗忘最后来源后别名不再召回而其余事实保留。图变化没有清空来源无关的详情。390×844 与 1280×800 的浅色和深色页面均无横向溢出，控制台无错误；[桌面两跳路径](screenshots/graph-path-desktop.jpg)和[手机反向路径](screenshots/graph-path-mobile.jpg)均为演示资料。未在真实浏览器人为模拟全部请求竞争窗口，迟到请求与 401 由门控测试覆盖。临时服务、页面和视口覆盖均已清理。

wheel/sdist 离线构建，wheel 安装到临时目录后从仓库外导入，验证包内 schema、路径界面、完整引用、两来源遗忘和查询预算；既有资源、API 文档、提示词、默认关闭的电脑能力、任务控制与完整 lifespan 也通过。没有下载依赖、修改用户配置或启动用户服务。
