# 2.11 完整标题目录审查

状态：实现、独立后审查、完整本地测试与真实浏览器验收完成；离线发行包验收完成，远端检查另行核验。正文归档已由 2.10 独立交付，本片补齐超过最近 200 条后无法从界面按标题发现旧记录的问题。

真实 SQLite/ASGI 反证表明旧第 201 条仍有详情和正文，但不出现在旧 `/api/sessions` 的最近列表；实际 app/SSE 门控还发现刷新会替换正在输入的搜索框并丢失焦点，失败时错误未呈现在记录页。新增独立的只读目录投影，不改变旧接口、唯一持续主身份或实时聊天状态。查询只针对标题，按字面匹配，不能称为全文或语义搜索。

只读参考 `/data1/codex` 的 thread 列表/元数据读取与按筛选条件先选集合、再以时间及 ID 分页。采用现有 SQLite 表和单一创建序索引；首次建索引需扫描既有会话，标题子串仍需扫描候选，不能宣称任意规模查询常数耗时。页内只投影实际摘要，完整 JSON 预算保留连续整项，游标绑定查询、存储实例与实际最后一项。数据变化并非 MVCC 快照，不为重新写入的创建时间提供遍历不变承诺。

创建时间只将有限的正 JSON 数值视为现代 MuLi 运行日期；缺失、非正、字符串、布尔及无限值显示未记录并排序为 0，不修改旧数据。更新时间只展示、不参与续页。未知会话状态保持中性，不把 idle 当作执行成功；全局活动状态继续使用团队与工作流的专门查询。

另已复现首连全局 SSE 从 0 继续跨批回放，且旧完成事件造成大量重复摘要请求，以及实时首屏仍携带原生消息字段。这些属于下一片独立资源治理，不把本目录的预算冒称成整个 bootstrap/SSE/浏览器内存上限；不能删除 hydrate 所需事件或随手跳到最新游标而漏掉初始化期间变化。

后审查复现 SQLite 将空 BLOB 的零长 substr 返回 NULL，导致合法空标题/状态误判为无效元数据。修复只作用于 SQL 的 text 分支，空字符串保留为空，缺失和 null 仍为 null；新增两项核心与一项 HTTP 回归在修复前失败、修复后通过。独立审查另以 73 行混合数据验证排序、NUL/Unicode 字面查询、删除锚点、重开资料库、整数精度与完整 JSON 预算，并验证迟到错误、DOM 换主、删除确认换窗和刷新中最后失效；十项后审查门控通过，无新增 P1/P2。

最终本地 1614 项 Python 测试通过、1 项 macOS 专用冒烟在 Linux 跳过（27.46 秒）；Ruff、156 个 Python 文件格式、72 个源码文件严格类型及 83 个包的离线锁文件检查通过。目录核心与 HTTP 专项共 76 项，前端整套 219 项通过，其中新增 22 项目录门控。测试使用临时 SQLite、ASGI 和实际 app 函数，不调用真实模型。

真实浏览器连接临时服务，超过最近 200 条的旧任务通过字面查询 `%_ archive` 找到，能够进入旧详情、正文归档并返回原目录；分页与未提交搜索词独立保存。真实 EventBus/SSE 传输明确模拟的开始、增量和结束事件时，目录页、搜索焦点及主对话草稿保持。模拟传输不代表真实模型运行。另一临时实例验证 205 条记录中的空标题和缺失标题分别显示，120 个 emoji 查询正常提交；主身份入口回到同一个持续对话，草稿不变。

1280×800 深色桌面和 390×844 手机浅深主题均无横向溢出，顶部导航可见，最终页面无 JavaScript 错误。截图：[桌面](screenshots/records-desktop.jpg)、[手机](screenshots/records-mobile.jpg)。专用页面、视口覆盖与临时服务已回收，未改用户服务、调用设备、安装大型依赖或下载模型。


wheel/sdist 已离线构建，源码树外临时安装通过 CLI、资源、API、生命周期和默认关闭的电脑能力检查。安装后的真实目录 API 在 1000 字符完整 JSON 预算下逐页读回全部 205 条记录，旧标题可进入正文归档，空字符串与 null 保持区分；GET 不写数据库、不创建任务，持续主身份不变。发行版本、changelog、wheel 与 sdist 元数据一致。远端矩阵和发布将在精确签名提交上分别核验，不将本地安装通过等同于发布完成。
